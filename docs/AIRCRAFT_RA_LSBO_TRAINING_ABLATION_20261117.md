# RA-LSBO 冷启动独立训练对照

## 研究问题

PR115 已在相同前缀上比较过预测，在全程搜索中比较过独立训练和共享核参数。PR116 则发现首解后交给原版 LSBO 可改善全程 RA-LSBO 的逆风能耗。这里把两项设计合起来，在新种子上检验独立训练是否提高冷启动找到可用解的速度，并在同一个原版后端下观察终点。

| 臂 | 首解前 | 首解后 |
| --- | --- | --- |
| ra_to_lsbo | 原有 RA-LSBO，目标和各风险头分别选取分组核带宽 | 原版 LSBO |
| ra_joint_to_lsbo | 相同 RA-LSBO，最大化各输出头边际对数似然之和，共享一组核带宽 | 原版 LSBO |
| logcei_to_lsbo | PR115/116 的仓库 LogCEI 适配版 | 原版 LSBO |

前两臂采用同样的潜空间目标输入、层级显式风险输入、目标与风险区间反馈、核参数网格和采集规则。共享核仍保留各输出头和各自似然。本对照检验带宽分别选取的贡献。LogCEI 使用相同的初始数据、冷启动候选池、预算与接力后端，保留自己的模型和采集规则。

沿用 PR116 的 140 km 任务、20 s 积分、4 m/s 逆风和无风增载 24 kg。每工况使用 40 个新随机种子，跨臂配对，每种子 4 个共享初始设计、128 个共享冷启动候选，每臂 20 次在线评价。评估尝试均计入预算。发现首个完整、满足约束且有可观测能耗的设计后，从下一次调用起把全部已评价历史交给原版 LSBO，并关闭原版早停直至用满预算。初始已有解时三臂直接用同一个原版后端。始终未发现时由各自的冷启动引擎用满预算。

## 主终点和判据

主比较为 ra_to_lsbo 减 ra_joint_to_lsbo。分析样本为初始无可用解的配对种子。若在第 1 至 20 次在线评价找到首解，取该次序号。未发现计 21。报告种子内差值的均值及 95% 配对 bootstrap 区间，负值表示独立训练更快。逆风和增载各自报告，保留差异方向及区间。两工况均支持提前才主张跨工况收益，单工况结果仅用于该工况的结论。

次要结果为同预算发现率、终点可用性优先的胜负平和净胜、双方都有解时的能耗差和分母。LogCEI 是外部次要对照。报告全种子结果作为补充。输出逐种子的计划覆盖、模型决策和拟合失败覆盖次数，核查实际发生的训练暴露。验证器核对共享核选择、候选池、观测前缀、首次可用后的交接和全部在线开销。初始已有解种子的三条原版搜索轨迹必须完全一致。

## 运行

| 配置 | 共享初始 + 在线 | 总降阶评价数 |
| --- | ---: | ---: |
| training-smoke | 8 + 36 | 44 |
| training-headwind | 160 + 2400 | 2560 |
| training-payload | 160 + 2400 | 2560 |

Smoke 使用旧种子检测初始已有解及初始无解两条路径。正式共 5120 次降阶评价，不使用留出面板，RCAIDE/MDA 调用为 0。使用 Python 3.9.25，与 PR116 一样用 run_aircraft_ra_lsbo_comparison.py 依次 plan、run、verify。分析放在对应证据目录之外。结果中的 primary 给出预先登记主比较，comparisons 给出逐种子次要结果，training_steps 给出冷启动决策次数分类。
