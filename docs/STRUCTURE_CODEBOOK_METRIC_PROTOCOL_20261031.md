# 固定编码表尺度敏感性：事后离线研究，不是新BO版本

## 依据与假说

使用结果06dd926297f98e049bd753a8aedc67572971ba8f中的完整Windows语料输出。
本次是观察该结果之后设计的开发性研究，不冒称预注册确认性实验。
两个语料组32个前缀均完整重构；one-hot的SOC分组平均NLL仍优。
测试一个具体假说：固定GP离散长度网格对不同表示的任意整体尺度敏感。
无需再训练VAE；不调训练轮数、损失、潜维度、数据、约束或采集函数。

## 冻结设计

全部2任务×8种子9911--9918×2前缀0/29，选择corpus_reset和onehot。
reset用于隔离表示尺度，不含persistent额外训练和更新时滞；不表示其已成为最终算法。
每个表示使用保存的完整12构型编码表，而非重新训练的Linux编码器。
两种度量：legacy完全复用保存的归一化编码；unit_pair_median将全部离散块除以所有
不同合法构型对的RMS距离中位数（不按语料频数加权）。连续变量和激活掩码不变。
统一标量缩放保持构型距离比例，不旋转、不逐维拉伸、不引入物理标签、不改变可逆性。
中位数<=1e-12显式停止，不重抽样或自动调整阈值。该设置仅一个，没有扫描归一化常数。
同样处理one-hot，避免只为潜空间改善尺度条件。

使用同一现有GroupedMixedHead，连续网格(.05,.15,.4,1.)、离散网格(.5,1.5)。
每头仅用当前前缀选择网格；后续真值仅在拟合后评分。目标、SOC分别处理。
与原研究相同的80个历史设计，不引入资格面板或新设计真值。
两种表示×两种度量×32前缀×2头=256头拟合，最多2048核候选；VAE拟合0、
真实数学/飞机评价0、RCAIDE0、优化器运行0。无参数搜索、未知重试或自动扩跑。

## 控制与限制

先检查原语料ZIP/manifest及封存文件哈希，再关联原pilot当前前缀。
每个legacy头的预测均值差除以原输出scale、预测方差差除以scale²，二者均须<=1e-6。
共128个控制检查；不通过则保存差异并停止，不放宽阈值。
这验证数值预测兼容，不宣称跨平台GP权重或特征逐字节重放。
密度NLL、区间概率NLL、RMSE、Brier分别分析；0前缀有4个后续设计、29前缀只有1个，
按前缀分层并报告分母。观察目标来自旧策略，不能作为新策略反事实闭环结果。
即使缩放改善NLL，也不直接证明闭环收益或尺度以外的结构创新。

该分支仅分析工具和文档，不修改默认优化器、结构语料模块、冻结飞机方程或历史证据。
完整云端离线研究通过后不要求工作机重复；后续闭环需要独立协议及预算。
