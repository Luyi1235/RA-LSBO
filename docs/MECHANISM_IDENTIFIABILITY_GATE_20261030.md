# 下一研究阶段：先证明机制可辨识，再扩跑

这是2026-10-30 transfer结果之后形成的研发决策，不是已经完成的实验，也不授权任何昂贵模型调用。旧transfer候选保留可复现，不晋升默认、不继续只在旧Branin/Rosenbrock上调权重。当前分支只增加诊断工具。

## 优先级与产物

**A. 决策影响诊断（本次已实现）。** 用`tools/review_transfer_pilot.py`核验固定原始记录，导出试验、逐约束权重、最终调用差异及覆盖所屏蔽的模型首选差异。必须限定同历史、同池，不能将分叉后不同数据集上的分数差称为单独的权重效应。仅用保存的预测做一步重评分，不给替代候选补算目标。本次真实调用预算0。

**B. 任务与观测协议资格（下一项研发，不自动启动）。** 建立一个有少量分支、明确条件激活变量的低维机制任务家族。分支之间应存在真实目标/约束权衡，不能让basic分支处处弱支配；至少登记“目标相似且约束相似”“目标相似但约束错位”两个结构条件。不是把对RA有利的任务留下而删除不利任务，整个家族及参数在方法比较前冻结。允许在受控数学任务中计算分支参考最优/可行体积用于资格，但这些参考不能泄漏给优化器，调用另设账本。

观测视图应从同一个精确隐藏约束确定性地产生：完整值、仅合法符号、预先给定分辨率的有限区间。必须对每个输出证明/测试真值包含于区间、视图嵌套、开闭端点、未执行输出仍missing和状态不混淆。缺失目标不补罚值。区间宽度、查询成本和终止机制先登记，不能根据算法表现调整。现有数学符号任务继续作为回归任务，不改旧公式制造优势。

**C. 对照先匹配，再做闭环。** 固定phase潜空间、层级onehot、等权、自适应、随机发现后相同局部开发；先对共同历史/候选及不同信息视图检查预测质量和决策可辨识性，再启动闭环。为节约费用，离线共同池诊断可先做，不以离线评分冒充在线胜出。最终仍需官方CBOB在它支持的连续部分观测任务上做可核验复现；扩展到层级混合变量时另标适配身份、保留原公式与参数差异表。当前没有正式集成CBOB，不能把conventional_eic或本仓库混合GP改名为它。

## 必须回答而不能替换的四个问题

1. 模型预测有没有变化？精确值评分、区间概率和概率校准应分开，不把预测密度与目标优化质量混为一谈。
2. 变化有没有影响资格门控、模型首选或最终调用？必须分别计数，覆盖回退不能只记为“模型探索”。
3. 最终调用改变后，全部种子的发现成本/成功率及开发质量是否改善？不把单条轨迹更好当作全体证据。
4. 改善是否超过等权、onehot或简单混合策略，并值得额外时间？若无额外贡献，保留简单策略，候选停止晋升而不删负面数据。

非零最终调用差异只是识别优化效果的必要条件之一，不是性能充分条件。上述门槛不是论文理论贡献或任何安全保证。

## 后续预算与统计边界

下一轮先交付冻结任务定义、信息视图单元测试、资格面板方案、具体对照与完整预算；此文件不预先授权新pilot。不要为了继续工作自动重跑3,108/8,916次实验。冷/暖分层仍由合法初值产生，禁止换种子。冻结最终算法之后，再使用未查看的任务实例和种子，做有主要终点、效应精度和多重比较规则的独立确认。飞机MDA在数学机制和简化飞机资格之后单独授权。
