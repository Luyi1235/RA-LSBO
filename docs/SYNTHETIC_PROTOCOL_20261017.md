# 当前基线的扩展合成验证

在运行之前固定以下设置：种子 0 到 9；mixed、sparse、no_initial_feasible 三个既有场景；RA、去边界 RA、CBO、当前工作区 LSBO、Random 五种方法，共 150 组。

沿用 2026-09-30 原型的预算、初始化、风险门槛及训练开销，不根据本轮结果改动：每组总调用上限 112，初始化 88，校准窗口 40，更新间隔 8，候选池 128，表示 10 epochs，GP 12 steps。初始化也计费。所有提前停止、未知结果和无可行解运行保留。

本轮重新执行全部方法，因为工作区 LSBO 的 optimizer/surrogate 已更新。它包含约束、求解器域及成功概率筛选；不能将它描述为论文中仅使用统一罚值的算法。来源哈希随运行保存。本轮不用旧版结果与新版结果拼接。

主要报告最优可行目标、可行解发现率、实际调用、非可行调用和早停，并给出每个种子的配对结果。所有运行都可行时才报告该组最终最优均值；不删去失败运行后计算“成功样本平均优势”。本轮仍是原型诊断，不是飞机 MDA 优越性的证据。没有新真实 MDA 调用。
