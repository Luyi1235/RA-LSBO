# RA-LSBO：12–192 条真实初始评价下的 GP 样本量学习曲线

## 问题与依据

PR48 的独立种子测试没有发现潜空间相对于 One-hot 稳定的能耗与 SOC 预测优势。100 km 能耗 RMSE：潜空间 3665 Wh、One-hot 3657 Wh；140 km：潜空间 13451 Wh、One-hot 14353 Wh。SOC Brier 差异很小，按 8 个种子簇计算的区间跨零。

此外，PR48 每任务 96 个目标设计的 **completion 标签全为成功（96/96）**，完全没有隐藏完成失败。两种完成 GP 的低 Brier 因而无法证明失败识别能力。目标精确能耗标签只有 100 km 70/96、140 km 27/96。后续分析应同时报告有效标签、正负类别覆盖和 GP 与简单基线的差距。

## 冻结离线对照方案

两任务都仅使用 PR45 已有的 20s 真实共享 q_A 初始记录。每个训练 fold 使用一个固定 16 种子块（总 192 次真实初始评价）；每个 fold 的测试来自另一个完全不重叠、且未参加 PR48 GP 机制测试的种子（主种子第 257 个起）的 12 个 q_A 点。训练前缀 12、24、48、96、192 是同一固定训练块的嵌套前缀；所有规模及潜空间/One-hot 视图均预测同一测试集合，禁止评价真值泄漏。

训练真实飞机初值的来源：
- n=12：1 个训练种子，12 次已存的真实评价。
- n=24：2 个种子。
- n=48：4 个种子。
- n=96：8 个种子。
- n=192：16 个种子。
- 测试始终来自不同的 1 个种子，共 12 个真实初值。

每个训练规模从头拟合相同代码的 2000 无标签构型 VAE 及两类完整 GP/EP 后验；计算能耗 RMSE、每项约束 RMSE 和 Brier、假可行数、完成 Brier；同时计算只依赖训练集的常数均值/平滑可行率基线。约束边界子集固定为留出真值中绝对余量最小的 25%，仅作为事后评估分组，不参与选点或训练。

**重要科研限制：** 192 条真实评价来自不同种子，其物理评价成本是真实存在的。这个事后训练数据池不是 PR45 原始 12+18 在线算法免费得到的样本，因此不能据此声称原算法在相同预算下有效。140 km 任务原始小于 10% 的稀疏可行域标准仍未独立通过。

## 工作机 PyCharm 操作

使用新的 Git 工作树获取本 PR，在 Rcaide_vsp 中打开仓库根目录并运行脚本：

run_ra_lsbo_gp_learning_curve_pycharm.py

原始只读数据库目录默认设置为：

D:\LSBO\RA-LSBO-pr45-real-20261104_01\results\true_aircraft_12workers_20261103T173750Z

先在 Script parameters 填入：

--folds-per-task 1 --sizes 12,24

两任务数值试跑完成后，另建一个新输出目录运行默认参数（每任务两个 fold，五个训练规模）。也可在性能允许的情况下将 fold 增加至 4 或 8；若出现 GP 拟合异常保留报告中的 fit_errors 和控制台信息，工作机无需修改代码。

新结果目录自动位于 D:\LSBO 下以 RA-LSBO-GP-learning-curve-no-aircraft 开头，上传 learning_curve_report.json、learning_curve_predictions.csv、完整日志和固定 SHA 到独立 GitHub 结果分支。
