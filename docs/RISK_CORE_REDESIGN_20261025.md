## 2. 核查实现后需要改变的设计

### 2.1 从输出证据出发定义模型

CBOB 正文式 (11) 通过 Gaussian 与 probit 型似然分别利用数值及超限信息，
以 EP 近似后验。式 (6)–(10) 将边界探索放进采集函数。
这是比“先训练总成功分类器，再乘一个风险权重”更适合研究部分观测的起点。

然而，CBOB 已知哪一项约束违反的反馈条件不能直接移用到本项目：
任务求解器不收敛只证明评估未正常完成，并不自动证明最终 SOC、失速或能量余量超限。
失败日志中的未收敛中间迭代值也不能当作收敛设计的数值约束或严格界。
因此，新模型需要三类互不混淆的逐输出证据：

1. 审计有效的数值观测；
2. 有来源证明的单侧或区间观测；
3. 未知缺失，不进入该输出的似然。

完成状态和已经核实的失败原因另行进入完成/阶段模型。
部分输出可以在后续失败时继续有效，不以最终完成状态一刀切。

现有 `records.py` 将 `objective_observed` 与 `hidden_success == 1` 绑定。
它不能直接表达“目标已审计有效，但后续步骤发生已知失败”。
本轮新接口解除这一数据语义耦合，不改写历史记录或冻结实验。
旧记录自动迁移、日志证据提取和新概率模型仍需分别实现和验证。

### 2.2 清楚区分可行解发现和可行边界优化

已核查的 BE-CBO `BECBO.optimize()` 使用 `assert is_valid.any()`，
并以可行点的最佳目标值构建 EI；其后结合集成概率带、边界初始化和约束采集优化。
它不是不需要可行起点的通用冷启动方案。

新核心须在两个阶段采用明确、可复现的决策：

- 尚无可行解时，以首次发现为决策目标，保留全局与跨构型覆盖；
- 已有可行解后，检验论文原有边界优化方法，再研究额外失效信息的决策价值。

这两个阶段不能只靠改一个概率门槛混在同一公式中。
CBOB 正文的渐近结论也有完整约束观测等假设；其报告采用 `11*d` 初值后
再优化 100 次，不能直接推断在本项目 6 次在线预算里仍有收益或继承其理论保证。

### 2.3 重新定义风险与预算

分别记录：昂贵调用成本、已知隐藏终止、完成后的显式违规、基础设施未知结果。
总调用授权不是用户另行指定的允许失效次数，不自动等同于算法的风险预算。

拟研究的风险控制对象是序贯评估中的失败/违规成本。
首次发现阶段和已有可靠回退点的阶段须分别描述适用条件。
按序预测必须先保存，再揭示标签并更新；模型改版或表示变化时记录身份。
在线校准、累计违规率、单点可行概率、物理系统安全性属于不同命题，
不能用其中一个的经验指标替代另一个的保证。

### 2.4 使潜空间成为可检验部件

先在固定的、适合层级混合变量的表示下建立可工作的文献方法基线，
再在相同观测模型、初始化和选点器下替换成结构化潜空间。
只有表示替换本身产生可重复收益，才能支持潜空间的额外价值。
不继续将多种选点器、训练轮数和候选搜索差异同时计作潜空间收益。

## 4. 新核心的构成与原创性边界

计划使用独立的观测、概率模型、决策、实验适配四层：

1. **观测层**：逐输出数值/区间/缺失证据，另存完成与阶段证据；
2. **模型层**：先复现混合似然约束模型及完成模型，避免凭失败名称虚构物理标签；
3. **决策层**：明确区分首可行发现与后续优化，以文献原版为基线后再研究改进；
4. **适配层**：接入层级空间、可替换潜空间与 MDA，不由原 LSBO 选点器决定新方法行为。

第一项原创研究假设是：MDA 阶段性终止与部分有效输出，在条件构型空间中
提供了总体成功标签未利用的信息，合理的似然和决策能减少发现与优化的实际调用成本。
第二项假设是：潜空间能提高这种信息跨构型共享的效率。
可靠概率更新和有限预算边界探索继续保留为待检验研究方向。
这些仍是假设，通用混合似然、集成、在线校准和它们的组合本身不直接算原创。

先做明确的一项结构扩展和对应消融，再决定是否增加其他组件。
额外复杂度必须带来可观测的收益，不能通过换名称、更多模块或更多计算来证明价值。

## 6. 后续执行门槛

先完成选定文献核心的独立复现，验证似然、后验与原版采集逻辑；
再用完整、事前固定的廉价预算检查零可行初值与部分观测。
BE-CBO 若增加冷启动，单列为扩展版，同时保留有可行起点的原版比较；
涉及符号方向的转换须单独核对，不能把其 `C >= 0` 直接套成本项目 `g <= 0`。

后续完整评估协议必须先规定问题、采样分布、所有方法、全部初值成本、种子、
在线预算和终点，不根据已看到的负结果继续追加或挑选种子。
新完整计划超过用户 500 次授权上限时先说明总量，不拆成小计划绕过授权。
当前物理 300 次研究的资格/确认仍按原冻结规则执行；
新核心通过方法资格之前，不启动预留的物理优化方法比较。

原实现与负结果保留用于历史对照，新方法从独立核心产生完整证据，
不能把此前版本的训练或结果拼接成新算法的确认实验。
