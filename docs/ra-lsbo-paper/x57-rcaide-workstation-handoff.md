# 工作机 GPT 交接｜RA-LSBO 的 X-57/RCAIDE 冷启动试验

## 1. 项目背景与本轮目标

仓库为 [Luyi1235/RA-LSBO](https://github.com/Luyi1235/RA-LSBO)。LSBO 是课题组用于层级混合变量飞机设计的潜空间贝叶斯优化方法。RA-LSBO 保留原 LSBO 的设计表示、目标与工程约束代理，并引入完成风险代理。研究问题是小样本冷启动时，部分评价反馈和构型层级能否帮助优化器更早获得可用设计，以及这种收益是否延续到更低的可行任务能耗。

两条代理分支处理同一批评价结果。性能分支用实际获得的目标与工程约束观测。完成风险分支用已核验的完成状态和部分反馈，通过构型层级共享风险信息。冷启动阶段在工程预筛后的候选中按预测完成概率选点。获得足够可用设计后，用完成概率加权原 LSBO 的性能改进评分。定版使用贪心完成概率选点，并在累计取得 3 个可用设计后切换。两步前瞻是其他实验中的对照策略。

上一阶段已用降阶电动飞机评价器完成 32 次主实验和 64 次外部预算敏感性运行。它们提供了初期算法证据，完整数据见 [实验归档与绘图口径](https://github.com/Luyi1235/RA-LSBO/blob/d2211335485fd43e8f2faee909a5f76beb8c197a/docs/ra-lsbo-paper/budget-plots/README.md)。这一阶段迁移到基于 X-57 的参数化飞机设计族和 RCAIDE 任务评价。原始变量表含 14 个连续变量和 5 个离散变量，实际启用的子空间随推进布局及其他构型选择改变。先以仓库已有的翼尖推进和前缘分布式推进为两条分支，实际变量域以冻结的任务配置为准。

历史 RCAIDE 审计覆盖 55／65 nmi 两个旧任务。共 37 次启动，其中 15 次完成并获得精确目标值但无可用设计，21 次求解不收敛，1 次未结算。旧的不收敛记录没有可判定的非解析工程约束符号。55 nmi 是资格试验的候选起点，当前任务的可行区和反馈接口需要重新确认。先完成代码开发、模拟 worker 验收及资格试验计划。真实 RCAIDE 调用按工作机运行额度登记，正式批次在资格结论之后冻结。

## 2. 三个实验臂与结果口径

| 实验臂 | 策略 |
|---|---|
| `lsbo_native` | 原 X-57 LSBO 构型编码、候选生成、目标与约束代理、采集和局部搜索。接入统一的评价和预算账本。 |
| `structured_sign` | 加入结构化完成风险代理，用定版支持的完成／失败符号反馈。两阶段采集规则与完整方法匹配。 |
| `structured_interval` | 完整 RA-LSBO。保留可解释、经核验的部分反馈范围。与符号臂保持候选生成、阶段切换规则、工程筛选、回退和目标约束数据口径一致。 |

同一设计可以完成仿真并报告精确目标，但违反工程约束。可用设计要求任务正常完成、目标为有限精确值且满足所有必需工程约束。数值非收敛与基础设施故障分别记录，后者的状态为未知。把明确的物理区间和可用的状态反馈分开，只有与潜在风险指标有可靠对应关系的观测才进区间似然。部分任务能耗留在独立字段。三臂均使用各自在线获得的结果，初始化之外的轨迹彼此独立。

## 3. 工作机开发顺序

1. **核对物理契约。** 在现有克隆检查原 LSBO 源、X-57 模型、RCAIDE 与 Python 版本、任务配置、变量激活规则和可记录的工件。把采用的路径、提交和文件哈希写入运行计划。复用原 X-57 worker 隔离方式，通过 mock worker 验证封装。注意工作机曾使用 Python 3.9.25，先在本机实测，不默认使用更新版本才有的接口。
2. **接入原 LSBO 基线。** 单独建立实验分支和新的 runner，保留原性能模型、选点和局部搜索。用固定候选和保存的观测作回放，核对原提案与更新。遗留 LSBO 有连续缺失目标停止规则。若需要完整预算的公平对照，单独标记 `lsbo_full_budget`，仅调整该停止规则并记录差异。基础设施异常的停止和计费政策对各臂一致。
3. **接入风险代理。** 把 X-57 的实际构型属性接入层级核，把物理反馈变成结构化结果。共用完成／失败的可信观测类型，符号臂只保留符号，区间臂使用经过验证的范围。沿用定版两个阶段的排序和回退。缺少可信区间时，应在资格报告中标出本次只能检验哪部分机制。
4. **实现共享初始化和闭环账本。** 每个种子的初始设计只评价一次，三臂读取同一有序观测前缀。工程预筛拒绝、实际启动、结果结算和中断分别记录。实际发起 RCAIDE 的调用计入费用。保存候选、构型、激活变量、阶段、选点来源、完成概率、目标与约束可观测性、工件位置及耗时。跨种子可并行，同条 BO 轨迹按顺序使用该条轨迹自己的最新观察。
5. **模拟验收后提交资格计划。** 本地测试两构型的激活映射、共享初始化计费、完成但违约、有效和无效区间、普通非收敛、基础设施未知、阶段切换、回退、提前停止和无可用解。再拟定 16–24 次 RCAIDE 资格试验，覆盖两条构型分支及少量重复点，记录可复现可行解、反馈类型覆盖、实际耗时和工件。资格点与历史观测留在正式试验训练数据之外。

## 4. 初始点与在线预算

| 文献及算例 | 初始点 | 序贯评价 | 总预算 | 初始占比 |
|---|---:|---:|---:|---:|
| [SCBO 工程约束算例，§4.1](https://proceedings.mlr.press/v130/eriksson21a/eriksson21a.pdf) | 10 | 90 | 100 | 10.0% |
| [BE-CBO 移位合成约束基准，图 11](https://proceedings.mlr.press/v235/tian24g.html) | 10 | 190 | 200 | 5.0% |
| [ArchSBO 隐式失效喷气发动机构型算例，§4](https://arxiv.org/html/2504.08721v1) | 113 | 187 | 300 | 37.7% |
| X-57/RCAIDE 主设置 | 32 | 288 | 320 | 10.0% |

比例用于交代初始化成本与在线预算的取舍。X-57 初始设计按两个推进布局各 16 点预先固定。先审计关键离散子层级和经过工程筛选后每个分支的候选供给，再在各分支的有效连续空间做空间填充。构型覆盖和预筛规则可以用于生成初始设计，RCAIDE 结果只在冻结后用于判定可用性。具体启用层级、分支配额、种子、初始名单与固定能耗目标先登记。若要比较 16 个初始点，使用同一空间填充顺序的嵌套前缀，各自仍用 320 次总预算，单独登记运行成本。

以共享初始数据中的可用设计数报告 **0 个、1–2 个、至少 3 个**三组，同时保留所有种子。0 个对应本文冷启动子组，1–2 个仍处于定版流程的可用设计获取阶段。若已登记的正式种子中冷启动案例很少，直接报告该组规模与局限。需要增加冷启动证据时，另行登记预算与场景。

主设置每种子共享初始化 32 次，三臂各做至多 288 次在线评价，实际 RCAIDE 调用上限为 896 次。六个配对种子、单一任务合计上限为 5,376 次，资格试验另计。实际运行规模按资格试验耗时、工作机资源和已登记预算确认。

## 5. 回传与论文指标

- 第一轮交付包括开发分支与提交、原 LSBO 和物理配置身份、改动文件清单、可运行命令、mock 验收结果、候选／反馈字段表，以及带估算成本的资格试验计划。
- 正式指标包括总评价次数、首次可用评价次数、首次达到预设能耗目标的评价次数与达标率、各预算节点的最佳可行能耗、失败类别、实际费用和墙钟时间。报告第 32、48、64、128、256、320 次累计节点。主设置的第 32 次是共享初始化终点，第 48 次包含 16 次在线评价，第 64 次包含 32 次在线评价。没有可行解的种子保留，最佳可行能耗留空，首次达标的未发生事件按预先指定的统计口径处理。
