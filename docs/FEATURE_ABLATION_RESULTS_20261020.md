# 历史风险特征消融结果

本项只使用已检查过的历史，新增真实 MDA 为 0。协议见 `FEATURE_ABLATION_PROTOCOL_20261020.md`；不修改或读取当前 120 点真实验证的结果。

后续状态：同日另行完成了已事前登记的次要特征边界验证，使用同批新设计的独立留出、不增加 MDA，详见 `BOUNDARY_RESULTS_20261020.md`。本历史诊断的表格与适用范围保持不变；历史相对顺序未稳定延续到新边界样本。

## 设置与核验

沿用 v4 随机历史 180 训练、60 校准、60 留出，外加四种策略的各 200 条未用于拟合的设计。共 860 个测试块内设计、跨块去重后 858 个设计；不同测试块不是独立重复。

四种特征、五个 RF 种子共 20 个模型，17,200 条预测。潜空间为同一冻结表示，不能把五个 RF 种子当作五次独立 VAE/飞机实验。20 个 sigmoid 均满足原启用门槛。所有预测和原始标签、指标、49 个来源文件和快照均通过独立核验；没有调用物理求解器。潜空间 seed 0 重现前轮 RF 模型身份和校准段预测。

维数分别为 latent 32、hierarchical_onehot 52、plain_onehot 33、continuous_mask 28。维数影响默认 RF 特征子采样，比较的是既定特征管线，不声称因果分离了单一因素。

## 校准后评分

下表为五个 RF 种子上的平均 Brier，越低越好，不是五次独立实验的统计估计：

| 测试历史 | 潜空间 | 层级 one-hot | 普通 one-hot | 连续量与掩码 |
| --- | ---: | ---: | ---: | ---: |
| 随机留出 60 | 0.08190 | 0.07783 | 0.06149 | 0.08530 |
| LSBO 200 | 0.01998 | 0.01603 | 0.01595 | 0.01731 |
| Mixed-GA 200 | 0.00226 | 0.00135 | 0.00092 | 0.00125 |
| One-hot GP-BO 200 | 0.01345 | 0.01416 | 0.01372 | 0.01414 |
| RF-BO 200 | 0.04569 | 0.03911 | 0.03470 | 0.03575 |

普通 one-hot 在五个块中的四个块平均损失较低；潜空间在 One-hot GP-BO 块略低。不能据当前结果声称潜空间风险分类稳定优于 one-hot。混合 GA 的 200 个点均可行，低 Brier 不表示该块检验了失败区分能力。

0.8 固定阈值下，潜空间与普通 one-hot 的平均“接受数 / 接受中违规数”分别为：

| 测试历史 | 潜空间 | 普通 one-hot |
| --- | ---: | ---: |
| 随机留出 | 29.0 / 0.2 | 32.8 / 0.0 |
| LSBO | 186.8 / 2.0 | 193.8 / 2.0 |
| Mixed-GA | 199.8 / 0.0 | 200.0 / 0.0 |
| One-hot GP-BO | 186.8 / 0.4 | 186.2 / 0.6 |
| RF-BO | 168.8 / 4.4 | 183.4 / 4.4 |

小数来自同一批历史上的五个 RF 模型均值。RF-BO 的平均 Brier 降低，但接受的违规数仍为 4.4，说明总体概率评分不能替代阈值处的实际风险比较。

## 对后续工作的影响

不替换正在执行的冻结真实模型，不用本轮独立留出选择特征或阈值。后续真实优化对照需要保留 one-hot 风险模型作为强基线，避免把潜空间本身默认当作已成立的创新收益。

当前比较没有改变目标或约束 GP，也没有改变候选搜索，因此不回答哪种完整优化器更优。隐藏失效机制的同契约正例仍不足，机制分解不能靠该最终可行性诊断代替验证。
