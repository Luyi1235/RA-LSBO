# 约束感知风险评分：探索性诊断与新点验证

制定于 2026-10-17：已观察到原冻结试点的三个边界点失速违规，因此本方法是针对已知失败的探索性修正，不能把原六点当作独立确认。

固定新原始分数为：最终可行 RF 原始分数与全部必需昂贵约束 GP 边际满足分数的最小值。不做独立概率相乘，也不把最小值宣称为真实联合概率或置信下界。沿用原来的正则 sigmoid，将这一新分数映射至最终可行标签；全部启用门槛保持不变。

历史仍只用原试点来源的前 180 条拟合表示、RF 和各约束 GP，后 60 条校准。模型不得使用原六点标签拟合。使用原六点与既有 860 条历史测试记录做探索性诊断，明确这些数据已被查看，不作为新的独立验证。不根据结果试选多种公式或门槛。

若所有必需约束 GP 可用、原 RF 已拟合且校准器满足原启用规则，则准备新的最多八点前瞻检查：同 v4 物理契约，rng=20261018，四开发/四边界交替，排除源历史 300 点及前一计划全部八点。使用新校准分数选点，同时在执行前保存旧模型和新模型对完全相同候选的预测。实际停止条件仍为累计三个非可行/未知或首个未知/基础设施错误；预算最多八次、风险额度 4.8、开发阈值 0.8，无重试。

该小批量在用户已批准范围内执行，授权来源写入请求；不是将第一次停止的试验恢复，也不合并两个试验来挑选好结果。新的八点检查是概率/接口检验，不是优化算法对照；新旧预测按相同实际完成点做配对评分，未执行点不填补结果。没有隐藏失效正例时继续保留机制验证不足的结论。
