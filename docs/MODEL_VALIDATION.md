每次预测只使用之前的历史记录训练 VAE、目标和约束 GP、风险头。完整设计语法属于事前已知信息；未来目标和标签不得用于表示训练。

`forecasts.jsonl` 在加入当次观测前写入并刷新。`scored_predictions.jsonl` 随后附加真实结果供评分。每条预测包含训练编号、表示快照、各头训练样本数及拟合状态。源日志、评估器配置、所复用 LSBO 模块和 RA 模块的哈希保存在报告中，结束时复核源文件及模型代码没有变化。

这属于从已结束日志重建的历史样本外回放，不是前瞻性试验；候选由原 LSBO 产生，并非由 RA-LSBO 选出。

## 测试与边界

在上述模型环境运行 `python -m unittest discover -s tests -v`，52 项测试全部通过，无跳过。覆盖数据协议、缺失值和掩码、部分有效约束、非激活变量不变性、候选范围、类别不足降级、训练身份和表示版本一致性、修改未来目标不影响之前预测，以及先保存预测再附加真值。

本轮未改变原 LSBO 的代码、物理参数或历史日志，没有新增 MDA 调用。阶段化 worker 诊断、概率校准、风险预算账本、候选选择及配对算法对照仍待完成。

机制头概率是在对应标签可观测样本上学习的，受阶段删失影响；不能直接解释为全设计空间的无条件风险，也不能将各机制概率相乘得到联合成功率。最终可行性目前是独立二分类原始估计。

GP 标准差是当前固定表示和模型假设下的预测量，不包含全部表示误差或物理模型误差。此次单运行、20 次预测既不足以证实概率可靠性，也不能证明 RA-LSBO 改善最优能耗、失败率或评估效率。
