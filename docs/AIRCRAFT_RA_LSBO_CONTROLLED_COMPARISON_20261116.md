# 冷启动 RA-LSBO 主对照实验

问题是目标性能与风险的独立代理训练，以及由此产生的风险感知决策，能否增强层级混合变量飞机设计中的 LSBO。冻结现有双视图 RA-LSBO。目标代理用潜空间，风险代理用显式层级掩码，使用原有区间反馈、分组核和风险采集策略。这一轮保持原生 SOC 反馈与飞行任务，没有加入 PR114 的中止时刻代理。

| 臂 | 冻结方法与作用 |
| --- | --- |
| ra_separate | RA-LSBO 双视图，目标和各风险头分别按自己的边际似然选择核参数 |
| original_lsbo | 仓库冻结原版 LSBO 的直接运行，使用原生潜空间生成、约束和停止规则，GP 迭代数 45 |
| ra_joint_kernel | 匹配 RA-LSBO，对所有输出联合最大化边际对数似然和，选一对共享的分组带宽 |
| ra_explicit | 匹配 RA-LSBO，将能耗代理的潜表示替换为显式层级表示，风险代理与采集保持一致 |
| logcei | 仓库 LogCEI，独立 GP 与完成/约束分类器，几何筛选后的同一候选池 |
| scbo_adapted | 仓库 SCBO 适配，受约束 Thompson 采样、层级混合变量信赖域，几何筛选后的同一候选池 |

共享带宽对照保留与独立版本相同的输入视图、各头似然、可见标签和采集规则。它测试联合共享核参数相对独立训练的贡献，预测仍用条件独立输出头。显式对照测试固定候选池下目标代理的潜表示贡献。原版 LSBO 保持自身候选生成。对原版的比较衡量完整求解流程差异，不能从该对照单独识别原因。LogCEI 和 SCBO 是仓库已有适配，后者用点级 Bernoulli 可行抽样，并非官方方法逐项复现。

所有臂每种子共享 4 个初始点、相同设计约束和最多 20 个在线调用。五个池方法共享 128 个候选，禁用 RA 局部增广。原版 LSBO 和池方法使用相同的几何预筛，实际中止均计费。提前中止按真实任务完成状态给所有臂提供同样类型的反馈，完整性、能耗可观测性和约束值保持区分。保留原版连续五次缺失目标的停止规则，剩余调用不转配。诊断早期同预算性能时额外报告第 8 次总评价前的发现率，此时在线调用尚少于五次。

## 预先固定的判读

主要终点是初始无可用解种子的配对受限首解调用数。20 次在线调用仍无解记为 21，另报第 24 次总评价时的发现率、每个种子的实际调用数和早停原因。第 24 次总评价的可用性优先、能耗次之，报告配对净胜率。双方有解的种子另报 Wh 差与分母。各工况分别报告全种子与初始无解子组的结果，以及相对于每个外部方法的差和 95% 配对种子 bootstrap 区间。

独立训练的预测对照固定在同一 LogCEI 实际训练轨迹上。第 4、8、12、16 次总评价后的两组预测共享同一 VAE 快照、同一训练前缀和 32 个留出设计。留出评价发生在全部在线调用之后。报告留出构型等权的完成和可用 Brier，先按种子平均，再做配对。任何模型失配单独报告。原版对比衡量整体加强，联合训练对比识别训练机制，显式对比检验潜表示，外部对照衡量方法竞争力。首解、校准与最低可用能耗各自判读。

## 配额

降阶模型为 140 km 航程和 20 s 积分步长。正式两工况是 4 m/s 逆风和无风加 24 kg 载荷。每工况 24 个新种子，跨臂配对。使用现有 Rcaide_vsp Python 3.9.25，先跑测试和 smoke，再跑两工况。RCAIDE/MDA 均为 0。

| 配置 | 共享初始 + 在线上限 + 留出 | 评价上限 |
| --- | ---: | ---: |
| comparison-smoke | 4 + 18 + 12 | 34 |
| comparison-headwind | 96 + 2880 + 768 | 3744 |
| comparison-payload | 96 + 2880 + 768 | 3744 |

总上限 7,522。用 run_aircraft_ra_lsbo_comparison.py 执行 plan、run 和 verify，verify 输出重算的 comparisons、trajectories 和 calibration_comparison。分析文件放在输入证据目录之外，便于重放封存文件哈希。
