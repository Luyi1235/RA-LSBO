# RA-LSBO 机制数据与完整系统验证

日期：2026-10-21。主实验：
`runs/system_validation_v5_20261020T192312Z_5f6531eb`。

本轮已完成授权范围内的真实补采、全新留出校准和24个完整系统对照。
真实任务失败头有训练支持，但其余四类没有真实正例；
完整RA没有稳定优于原LSBO。因此，不能将实验完成写成
“五类机制数据均已充分”或“完整组合已证明提高优化效率”。

8方法共享632条初始历史，每方法3个配对种子、每运行12次新增MDA。
全部24个真实运行正常完成，保留全部结果。共同历史最优为
42809.06062435 Wh；共享补采和校准使历史最优从43251.97582513 Wh
改善的部分不归给任何优化器。

物理任务采用14连续、5离散变量的工程分支，不是新版论文24变量的精确复现。
原300点廉价筛选后随机历史可行比例为59.0%，本物理任务没有证明可行域稀疏。

## 校准与组合收益

在实际新增选点上核对216条已保存预测，未用校准拟合块冒充独立效果检验。
完整RA的36个选点中，最终可行性原始Brier为0.04141271，
校准后为0.05325908，校准没有改善这项指标。
去机制版本为0.05373853到0.06299169；one-hot版本为
0.01775183到0.05800266，也均退化。
这些是同一方法同一批选点上的配对评分；不同方法选点不同，
不能据此直接对风险特征的可靠性跨方法排名。

本轮只有一种实际可训练隐藏失效，其标签与总体隐藏成功互补。
因此需要区分总体隐藏事件模型的作用与分解机制头的额外作用，
不能将去机制对照的差异全部归因于“五机制分解”。
共同参考模型的560条训练标签完全互补，64棵RF树的划分相同、
叶节点类别概率相反，容差为1e-14。72条留出记录中，加入总体隐藏成功项
改变1条原始最终评分，在此基础上加入机制头改变0条。该证明只涉及原始
RF分量，不代表包含边界不确定性选点的整个算法等价。

实验后区域迁移诊断同时移除锚点及其全部邻居，禁止新校准和优化数据进入训练：

| 留出探测锚点族 | 风险表示 | 剩余训练正例 | 留出正/负例 | 失败召回@0.5 |
| --- | --- | ---: | ---: | ---: |
| 5 | 潜空间 | 11 | 15/6 | 0 |
| 5 | 层级one-hot | 11 | 15/6 | 0 |
| 19 | 潜空间 | 15 | 11/10 | 0 |
| 19 | 层级one-hot | 15 | 11/10 | 0 |

该诊断只覆盖两个预定义探测锚点族，不覆盖新校准另外出现的失败构型。
结果不足以支持任务失败模型对新区域的泛化，不能以正例数量达标替代。

本轮72条滚动校准窗口大于每运行12次优化上限。原始编码器、RF及GP
重训时吸收的是较早校准记录，新增优化标签尚未移出留出窗口；
新结果仍影响最优值、已评估集合和候选池。CBO使用全部已知数据，
原始训练样本数与RA不同。本轮不能证明长期在线表示和风险学习的稳定性。

去校准版本同时改变原始风险加权EI、风险扣减和选点模式；
去机制版本同时移除总体隐藏成功项；one-hot消融只替换风险特征，
目标/约束GP仍用新表示。RA/CBO从512个合法候选中选点，
原LSBO保留原生搜索。上述差异随结果披露，没有按结果修改冻结算法。

全部54个真实拟合checkpoint均完成280种训练语法构型的100%恢复。
首个完整RA快照的编码均值逐维方差约102到1361，不能宣称已经匹配
标准高斯潜先验；语法内恢复也不是未见构型泛化或优化收益的证明。

## 研究结论

与 `RA-LSBO任务规划.txt` 的六项工作对应：

| 规划工作 | 已交付 | 本轮仍未满足的研究证据 |
| --- | --- | --- |
| 统一MDA返回结构 | 掩码、隐藏/显式/未知分离、原始响应及严格部分观测规则 | 前三类构造错误仍缺独立阶段归因 |
| 结构化潜空间编码器 | 新VAE、多视图、更新/checkpoint及语法恢复核验 | 未证明先验匹配、未见构型泛化或风险预测稳定领先 |
| 目标、约束与失效多头代理 | 1个目标及6个昂贵约束GP、总体风险与五类机制接口；解析约束直接计算 | 仅任务失败头有真实训练支持，GP未学习跨约束相关性 |
| 可行性校准 | 独立留出拟合、分组/合并事件、降级与实际选点评分 | 本轮实际最终可行性Brier未改善，无安全覆盖保证 |
| 风险感知候选生成 | 风险账本、开发/边界选点、统一审批及原LSBO对照 | 经验风险扣减不是保守置信下界，新增失败太少不能识别防失败收益 |
| 实验与消融 | 两个五机制受控案例、24个真实对照、权重恢复与来源审计 | 单任务短程、模块消融有操作策略差异，未证明跨任务稳定优势 |

用户任务规划中的六个软件模块已形成可运行框架。本轮补齐了实际训练、
多方法真实短程闭环、消融、来源审计及权重交付，软件测试218项通过。
研究验收仍有两项未满足：五类真实机制的覆盖与泛化，以及完整组合的稳定
优化优势。当前结果应作为已完成的有限验证及负面证据保留。
