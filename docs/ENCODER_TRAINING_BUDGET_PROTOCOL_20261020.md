# 结构恢复质量与训练预算诊断

初轮框架实验显示：新旧编码器在 60 epochs 下的语法内完整构型恢复率均偏低。该发现来自回顾性诊断，不能把编码器代码完成当成表示质量已足够。本方案在该观察之后制定，仅诊断结构训练，不增加真实 MDA。

固定新编码器的全部损失和退火设置，比较潜维数 4、8，与训练轮数 60、180、600 的组合，每种使用种子 0、1、2，共 18 次从头训练。使用与首轮完全相同的原 180 条目标监督和可枚举有效构型语法。不得改变目标域、样本划分、测试标签或变量域。

只报告语法内有效头准确率、规范化完整构型恢复率、解码熵、潜变量方差、训练损失、训练时间和 checkpoint 一致性。本项不读取校准/测试标签计算选优指标，不运行风险或优化比较，也不选择“最佳测试 Brier”的配置。

预先设定工程诊断标志：有效头准确率至少 0.97、完整构型恢复率至少 0.90。它们用于识别训练与解码瓶颈，不是论文原有指标、未见构型保证或风险安全界。若不满足，原样报告而不继续加轮数至通过。

相同种子在不同预算下的退火按各自训练进度执行，因此比较的是“完整预定训练预算”，不能将预算变化解释为只在最后一份模型上多训练。潜维数变化会改变网络与联合特征维数，只作容量诊断。

继续保留原默认编码器，不把本项结构指标用于宣称潜空间预测优于 one-hot。源文件及输入在执行前快照，执行后核对来源、全部 checkpoint 和结构指标重算。当前变量为 19 变量工程分支；本方案不声称复现论文 24 变量结果。
