## 3. 已实现相关多输出约束 GP

新增 `ra_lsbo/joint_constraints.py`，使用 BoTorch MultiTaskGP 的 ICM 模型：
`cov(g_j(x),g_k(x')) = k_x(x,x') B[j,k]`，`B = W W^T + diag(v)`。
按输出标准化，以已观察的“设计、任务编号、约束值”训练，支持不齐的观测掩码。
某输出缺失不会丢掉同设计的其他有效输出，也不会被补成满足。
廉价解析约束不重复拟合；数据不足的昂贵输出明确标为不支持。
支持联合协方差、跨候选/跨输出抽样、模型身份与 checkpoint 恢复。

新增 `ra_lsbo/joint_selection.py`，接入目标 GP、完成 GP、违反量恢复和候选池。
表示不一致时拒绝选点；缺失昂贵模型时明确回退收集样本。
后验不作为校准证书或风险折扣，每次昂贵调用仍按完整一次计费。
集成测试通过，但尚无新的在线优化效果实验。
ICM 本身是已有技术；本轮补齐框架缺口，原创性还需要协同决策和消融证据。

## 4. 已完成真实历史预测诊断

协议：`runs/joint_constraints_20261025/plan.json`。
使用同物理契约前 128 条历史训练表示与数值 GP；表示为 4 维、600 轮，
GP 为 60 步、模型种子 0。去重排除训练设计后评价 262 个保存的优化设计。
没有用这些留出设计训练表示或代理，没有新增物理调用。
干净对照只改变 ICM 秩；rank=0 是共享输入核的对角任务模型，
并非旧版每个约束独立学习 ARD 核的 GP。

| 越小越好的指标 | 对角任务模型 | 相关任务模型 |
| --- | ---: | ---: |
| 约束向量平均预测负对数密度 | -8.934368 | -9.902460 |
| 未校准条件可行概率 Brier | 0.012589 | 0.013025 |

联合数值预测改善，可行概率评分没有改善。SOC 与端口能量的任务核拟合相关系数约 0.973，
这是模型假设下的结构，不是独立测定的真实物理相关系数。
两个权重恢复及固定种子联合抽样核对通过。
对数密度包含拟合的代理噪声；可行概率用潜函数协方差与 4096 次 Monte Carlo。
仅评价输出完整的条件子集，未将隐藏失败补成数值余量。
数据已用于开发，单次模型种子不支持统计优越性或前瞻校准结论。
