# 飞机冷启动风险主动学习试点

在现有 140 km、20 s 积分步长的简化电动飞机任务中，比较同预算下的工程可行性概率学习。保留任务原名用于标识历史接口。新留出面板报告实际类别覆盖，旧任务标签不构成稀疏域认证。本试点使用 6 个新配对种子，属于单工况探索性实验。

## 对照和预算

每个种子有独立的初始化、选点池、无标签采集参考面板和评分留出面板。各角色同样使用均匀抽取离散构型和活跃连续变量，再过解析几何筛选。参考面板无仿真调用，留出面板在该种子的所有在线轨迹完成后才评价。不同臂选到同一点仍独立计费。每臂每次真实反馈后重拟合六个工程约束头。VAE 使用已有结构语料和共同初始反馈拟合一次，随后固定；同种子的潜空间臂共享同一表示。显式臂使用已有层级 one-hot 及活跃变量掩码。

## 采集准则与观察定义

预测采用仓库稳定尾部混合似然 EP GP，按当前前缀从相同 4×2 核网格选择。所有臂使用原始概率，无独立校准样本、无额外校准拟合。联合工程可行概率使用边际乘积近似。已知的解析几何约束由所有臂共用的预筛选处理。

新采集规则在当前 EP 高斯近似下，计算观察候选的失速、翼根弯矩和 SOC 约束符号后，参考面板上联合可行概率的条件期望方差。每个头的量由当前边际及跨设计协方差计算，使用确定性的 24 点一维求积，再按独立头近似组合。其他三个头在采集前瞻中保持固定。前瞻把所选三个符号当作可获得，用已有仿真通常返回的符号近似真实反馈，忽略异常导致的符号缺失，并且忽略实际返回的数值或区间幅度。真实反馈更新仍使用所有六头实际返回的精确、区间或缺失记录。数值异常或基础设施故障不产生工程约束标签。任一已知违规可确定联合不可行，其余缺失保留为未知。

此次只检验工程约束学习。目标能耗用于共用的初始 VAE 性能监督与轨迹诊断。评价完成风险的模型验证和原生 LSBO 目标搜索闭环属于后续实验。对参考面板的预期收益属于模型量，真实预测收益以独立已评价面板为准。

## 复核与判读

主比较为 n=48 的 brier_explicit 对 boundary_explicit 的种子内联合 Brier 差。IID 和覆盖是强对照。brier_latent 对 boundary_latent，以及同采集规则下潜空间对显式表示，作为预定消融。报告 n=12/24/36/48 学习曲线。Brier Skill 使用每种子共同初始已知标签的 Laplace 常数基线。报告联合和分头指标、可行召回、假可行率、五分箱校准和未知标签数量。首个可用可行解和最好已观测可行能耗作为描述性诊断。对只有一个类别的面板保留原样，区分指标未定义和数值为零。

只读 verify 复算归档哈希、账本、前缀及存档评分的选点顺序，并验证留出评价发生在在线评价之后。它不重拟合代理，也不重算存档采集分数。analyze 生成逐种子指标和配对差。科学判断依据配对方向、量级和可行召回，并保留阴性结果。试点没有预定显著性或默认方法升级门槛。

## 工作机执行与归档

在现有 Git clone 里从研究分支同步，用固定提交新建干净 worktree，使用现有 Rcaide_vsp Python 环境。在 worktree 外创建一个新的输出根，先运行单元测试、查看 pilot 计划，再运行 smoke。每个 Python 命令都检查退出码。smoke 必须完整结算 28 次、verify 和 analyze 成功，再运行 pilot 一次。对技术失败保留已付费记录、日志和失败目录，返回故障位置。

将 smoke、pilot、两个分析目录和执行日志上传到独立 results 分支。证据文件设置 Git -text 保持原始字节。运行目录内的 manifest 仅覆盖原始证据，日志和分析放在同级目录。提交后回传结果分支 URL、完整提交 SHA 和最终验收状态。
