# 边界验证的分析协议

制定于 2026-10-20，120 点验证启动后、校准段完成前。该文件仅补充执行后分析，不修改冻结模型、候选、60/60 切分、启用门槛或任何停止条件。

## 报告范围

训练/校准段用于拟合，不作为局部校准效果验证。主要评分只使用第 61–120 点中实际执行且标签已知的留出结果；无效、未知、未执行分别保留计数，不补标签。

四个预测来源按冻结计划比较：原 RF/全局校准、约束感知分数/全局校准、原 RF/本次局部校准、约束感知分数/本次局部校准。不可用的局部校准器保留空值，仅对双方都有预测的同一批点做配对差值。

固定报告 Brier、log loss、五个等宽可靠性箱、0.8 阈值的接受数及实际违规数，并按 outer、near、inner 三个原始分层列出。总体 Brier 不代替阈值处的接受风险。若提前停止造成三层样本数不同，同时标明这一点，不将其当作完整均衡留出。

## 配对不确定性

探索性区间使用固定种子 20261020、2000 次分层配对 bootstrap。每次在各层内重抽当前层相同数量的点，两种预测和真值使用相同索引，再计算平均逐点损失之差。报告 2.5%/97.5% 分位数；负值表示比较模型损失较低。

这些区间只描述当前所采集边界混合样本的差异，不是对全设计空间、独立种子优化收益或安全性的覆盖保证。小样本、主动选点及任何提前停止都必须披露。

## 排序与接受

正斜率 sigmoid 调整概率值，不改变对应原始分数排序。因此不能把局部校准的平均评分改善直接解释为新的排序算法贡献。另报告固定接受数 10、20 的候选选择结果；若实际留出不足该数量则跳过。排序统一用对应的原始分数并以冻结编号打破平局，避免饱和概率导致伪排序变化。

本轮不按留出结果挑选新公式、分层边界、种子或概率阈值。若要继续优化对照，先冻结下一项方案，遵守用户新授权的不高于 500 次门槛。

执行期核验补充（仍在校准段）：固定数量选择和 0.8 接受统计先在已实际评估且预测可用的候选上排序/筛选，再分别数已知违规、已知可行和未知结果；不先按标签是否已知删除候选。Brier/log loss 仍仅对标签已知点计算。冻结执行器的原有阈值指标仅覆盖已知标签，分析报告另列包含未知结果的完整接受统计，避免提前故障使接受风险看起来降低。该补充不改变任何公式、候选、阈值或测试划分。
