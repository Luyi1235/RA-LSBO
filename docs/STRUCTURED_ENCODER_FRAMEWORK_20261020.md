# 结构化潜空间编码器框架

本阶段优先补齐任务规划第二项，暂不执行此前提出的 192 次真实闭环试验。新增框架位于 RA-LSBO，原 LSBO、物理模型、历史执行代码与已冻结结果不修改。

## 论文衔接与实现选择

依据用户新版论文第 8–14 页的式 (5)–(20)，新增独立的结构化 VAE：

- 序数变量使用级别坐标 s=k/(K-1) 与平滑基 sin(pi*s)，名义变量使用可学习嵌入。
- 离散嵌入、重构和解码熵使用条件激活掩码；递归传播父级失活，避免默认值误激活孙级变量。
- 性能头的学习输入仅为 z，使用有效真实目标标准化后的 MSE；不把失败占位目标作为监督。有效但显式不可行的目标保留。
- 损失为重构 + beta*MMD + gamma*MSE - lambda*解码熵。重构按每行有效离散头求和再取批均值。
- 初始训练先重构，再逐步增加性能权重；熵权重在初始训练线性衰减。增量更新使用较低学习率、全部已获得有效目标与有效构型语法，并重新编码历史。

这些是与论文方法一致的实现方向，不是已恢复原论文完整实验代码。潜维数 4、宽度 48、名义嵌入维数 4、MMD 权重 0.05、性能权重终值 1、初始熵权重 0.01、25% 结构预热和随后 50% 性能权重爬升均为明确可配置的本地设置，不宣称论文规定了这些具体数值。MMD 采用三个 RBF 尺度的有偏估计；熵在同批后验样本解码分布上计算，性能监督使用编码均值。

构型语法可由变量定义枚举，不使用未评估设计的目标或可行性标签。语法规模超过现有枚举上限时明确拒绝，不暗中抽样或删除构型。

## 特征与代理接口

| 视图 | 输入 | 当前 14 连续 / 5 离散、z=4 的维数 |
| --- | --- | ---: |
| `paper_gp` | 掩码归一化连续量 + z | 18 |
| `latent` | 掩码归一化连续量 + 连续激活掩码 + z | 32 |
| `hierarchical_onehot` | 掩码连续量、连续掩码、有效类别指示及离散掩码 | 52 |
| `plain_onehot` | 规范化连续量 + 类别指示 | 33 |
| `continuous_mask` | 掩码连续量 + 连续掩码 | 28 |

所有视图从同一规范化物理候选生成，非激活值不改变结果，活动坐标超界直接拒绝。列名、维数和布局被纳入编码器快照；风险模型另外绑定具体风险视图，不能将一个视图的森林用于另一个视图。

`StructuredRiskHeads` 接入既有多失效风险头，`StructuredResponseHeads` 支持两种联合输入和现有目标先验/残差 GP。先验通过显式 z 切片适配既有 GP 均值接口，连续量不能绕过切片进入性能头；约束仍为独立 GP，不冒称联合相关模型。

## 更新、恢复与时间隔离

`fit(rows)` 为从固定种子重新训练；`update(rows)` 只接受严格延长且旧行完全不变的训练前缀。增量更新后旧风险、约束模型和校准器必须重建，不能保留旧坐标上的预测模型。

快照绑定训练编号、完整历史身份、目标监督编号、变量及激活规则、编码器配置、损失轨迹、权重、归一化器、随机数状态、语法和源文件身份。直接修改模型、语法或元数据将被拒绝。checkpoint 只保存权重张量和明确元数据，加载采用 `weights_only=True`，校验来源和可选的完整训练历史，不覆盖已有文件。

性能损失、标准化和代理训练仅使用传入训练前缀。语法结构训练不是标签泄漏；使用所有历史目标预训练后声称早期预测无泄漏则不允许。

## 验证顺序

先通过掩码、层级解码、损失分解、性能头输入、时间前缀、增量更新、checkpoint 及风险/GP/校准接口检查，再冻结实验方案。原编码器作为不可变参考，one-hot 作为强基线。后续比较分别区分表示、性能监督、熵、退火和 MMD，不将多个改动的总效果归因于一个因素。

现有历史及前一批边界标签均已被查看，后续使用它们的框架实验只能称为回顾性诊断。全新设计上的确认及完整优化收益需要另行冻结实验协议；不得把通过软件检查写成潜空间已优于 one-hot。

已完成的三轮诊断见 `STRUCTURED_ENCODER_RESULTS_20261020.md`。其中 8 维、600 轮配置通过训练语法结构恢复及三次历史增量保持检查，配置位于 `configs/structured_encoder_structural_candidate.json`；相应 `paper_gp`/`latent` 特征维数为 22/36。该配置的风险评分在历史与边界分布上仍无稳定优势，保留为显式候选，不改变默认设置。
