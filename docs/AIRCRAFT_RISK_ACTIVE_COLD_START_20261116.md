# RA-LSBO 面向层级混合变量飞机设计的冷启动风险主动学习

论文的问题是在真实任务评价极少、仿真反馈不完整时，下一次评价应放在哪里，才能最快改善设计风险判断。现有 PR103–109 的监督粒度、首解和结构裕量实验用于建立反馈的作用机制。本试验直接控制采集策略，使用相同反馈与风险模型评估早期学习质量。PR109 的保留裕量复验仍是单独的反馈消融。

## 风险、观测与主动学习

令 C 表示完成完整任务并得到可信精确能耗，F 表示在 C=1 条件下满足工程约束，U 表示获得可用设计。档案中的 completed 字段不能代替完整任务执行。可信物理中止提供 C=0，不提供 F 标签。数值、基础设施及不可判定结果按原适配器规则保留未知。预测 p_U(x)=p_C(x)p_F(x)，p_F 为条件可行性代理。认知不确定性通过两个 probit GP 的后验协方差影响相邻设计间的信息传递。各设计的风险概率是代理预测。实验仿真固定工况，并未估计随机飞行故障率。

在当前数据下，候选 x 的可判定反馈分三类 o，即任务中止、完成但违约、得到可用设计。令 y 是无标签参考设计，准则为对 y 加权平均的期望 Brier 降幅

`Δ(x) = E_y Σ_o [P(U_y=1,O_x=o) − P(U_y=1)P(O_x=o)]² / P(O_x=o)`。

由全方差公式，这等于在冻结的代理模型下，观察 x 对 y 的可用概率带来的期望平方变化。利用 GP 近似后验和跨设计协方差计算两点联合 probit 概率；通过两个分阶段头后验独立近似将反馈分支组合起来。参考集内每个出现的合法离散构型权重相同，构型内部均分。实际评价后用新数据重新拟合。准则未模拟未知分支、精确裕量、重新选核或噪声率，未知结果不伪造标签。现有连续约束头只用于诊断；本轮风险采集仅用三个任务级结果，所有策略接收同一粒度的任务级监督。

## 预设实验

两个工况为 140 km、20 s 步长的同一降阶飞机，无风与固定 4 m/s 逆风。每工况 16 个新配对种子。每个种子共享 4 次初值评价、128 个未评价选点池设计、96 个无标签参考设计和 64 个独立留出设计。每臂独立完成 12 次在线评价。留出点只在各臂全部结束后真实评价。首解出现后仍按原登记采集规则完成学习预算，以保持学习曲线可比。

| 臂 | 选点 | 风险输入 |
| --- | --- | --- |
| risk_coverage | maximin 覆盖 | 显式层级特征 |
| risk_greedy | 最大 p_U | 同上 |
| risk_pointwise | 最大 p_U(1−p_U) | 同上 |
| risk_active | 最大参考集期望 Brier 降幅 | 同上 |
| risk_active_latent | 同一主动学习准则 | 固定的结构 VAE 潜空间 |

显式特征保留条件变量掩码。潜空间使用 LSBO 已有结构 VAE，在相同初值及预设的 2,000 个无评价结构样本上训练并冻结。潜空间和显式主动臂对比同时包含风险表示与其GP相似度变化。风险采集先验、标签定义、候选与预算统一。新方法不主张首创不确定性缩减、约束分类或可行边界学习。

主比较是显式主动臂对显式覆盖臂。主要终点取每种子在 n=8、12、16 三个检查点的构型等权可用 Brier 均值。在每个检查点，对有可判定标签的留出观测在各构型内求均值，再对构型等权。所有种子进入主分析，包括已有可用初值的种子。两工况分别报告配对均值与 10,000 次固定种子的种子级配对 bootstrap 95% 百分位区间，较低为好。后续确认应要求两工况的方向一致，同时核对可行召回。另与贪心、点式不确定性比较，并做潜空间消融。在同一独立留出集报告逐检查点的可用、完成、条件可行 Brier 和召回，以及标签覆盖。首解作为次终点，初值无解子组在第 16 次仍未发现时按 17 计算受限调用差。预测改善与首解改善分别报告。

这是 RA-LSBO 冷启动风险阶段的研究，不包括首解后能耗优化。只有在该阶段得到可复验的主动采集收益后，才将获胜策略与原 LSBO 后半段接起来验证全预算收益。
