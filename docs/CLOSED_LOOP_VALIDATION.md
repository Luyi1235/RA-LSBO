# RA-LSBO 闭环与比较验证

日期：2026-09-30。当前已完成可运行的研究闭环和配对合成试跑，尚未证明方法优越性，也未启动真实 MDA。

## 代码与执行路径

新增的主要模块：

- `budget.py`：预算策略与单写入者追加账本。预约、启动、结算、取消分别留痕，写入并刷新后才允许实际调用。
- `selection.py`：最终候选池、稳定的 Log-EI、约束零边界与森林分歧评分、统一预算审批。
- `optimizer.py`：初始化、滚动训练 / 校准、开发、边界探索、无可行点发现与停止处理。
- `synthetic.py`：层级混合变量、解析预检、串行隐藏失败、独立数值约束及多约束同时违规。
- `legacy_benchmark.py`：直接复用现有 LSBO 优化器，不改原源代码；通过适配器把其所有合成调用也记入账本。
- `preflight.py` / `x57_live.py`：真实物理契约检查、默认关闭的原 worker 接口及单次授权请求。

所有 RA 候选，无论来自全局、局部、初始化还是恢复路径，都经过最终坐标规范化、廉价预检和统一审批。预测证据绑定候选哈希；修复或替换候选后必须重新评分。

当前是有限候选池优化，不是原 LSBO 连续潜空间优化器的等价复制。边界评分同时使用约束满足概率接近零边界的程度、森林预测分歧、目标改进潜力和 GP 标准差；它是明确记录的启发式，不是严格互信息或置信界。失效机制头目前主要用于诊断和校准，选择主要使用总体可行率与约束余量；分解机制的独立增益仍需专门消融。

## 预算语义

初始化和没有可靠校准支持的发现调用按每次 1 记最坏情况风险占用。经验校准可用的开发 / 边界调用按 `1-p_feasible` 记模型下预计不可行量。两者共享总额度，另记录实际非可行、明确不可行和未知结果数量。

这里的总风险记账是“最坏情况初始化 / 发现占用 + 经验概率下预计不可行量”，不是实际失败次数的确定上界，也不代表概率经过独立可靠性认证。真实研究中仍需审视分布变化。

预约即占用调用与风险额度；尚未启动的预约可以取消。启动后不因成功而退回历史风险记账。超时、崩溃、未知异常继续计费，不改写为飞机物理失效。被中断且结果不明的调用保持 unresolved，不自动重试。权威预检明确表示未进入 MDA 时不计昂贵调用。

账本包含顺序号、前项哈希和当前哈希，支持检测损坏和回放核算；这不是防恶意重签的密码学授权机制。恢复读取是只读的，不实现崩溃后自动恢复提交。重新执行同一个真实请求因已存在账本而被拒绝。

## 合成实验协议

最终结果目录：
`D:\LSBO\RA-LSBO\runs\synthetic_benchmark_20260930T133436Z_c5b0729c`

该目录包含总报告 `report.json` 和逐种子图 `paired_results.png`；每个方法目录保留 manifest、观测、预算账本、总结及模型拟合记录。原 LSBO 另保存其原生日志。报告状态为 passed，代码哈希在运行结束时复核一致。

试验共 3 个种子（0、1、2）、3 个场景、5 种方法，45 组：

| 场景 | 定义 |
| --- | --- |
| mixed | 层级变量、解析布置筛选、串行几何 / 网络 / 任务失败，椭圆可行约束及载荷约束 |
| sparse | 将同一椭圆在 x 方向的半径从 0.28 缩至 0.085，其他协议不变 |
| no_initial_feasible | 88 个共享初始化候选的 x 坐标限制在几何失败区，检查从无有效目标 / 无可行点起步的行为 |

每组上限 112 次调用，88 次初始化也计入预算。所有方法共享相同的初始候选及评估器；不免费提供校准标签。RA 最近 40 条作校准窗口，每 8 条新观测重新训练表示和所有头，再重新拟合校准器。旧校准器不迁移到更新后的表示。

RA 风险总额度 102，发现调用最多 8 次，边界调用最多 8 次，开发概率阈值 0.8；去边界消融将边界额度设为 0。该阈值基于经验概率，不是置信下界。校准器沿用上一阶段固定门槛，没有为了实验结果降低要求。

比较方法：

- RA-LSBO：本轮实现的经验校准与预算版本。
- No boundary：去掉边界采样，其余规则保持不变。
- CBO：使用相同潜空间与独立约束 GP；隐藏成功概率与各约束边际概率相乘，仅作为明确的独立性近似基线。
- Original LSBO：直接调用现有 LSBO 优化器，使用降低数值工作量的固定设置，而非另写一个冒名基线。
- Random：通过廉价预检的纯随机候选，不混入可行精英的局部邻域。

RA 的校准留出会减少原始模型的训练样本；比较方法可以使用截至当时的全部观测。共同可获取的数据和昂贵调用上限相同，但训练分配策略不同。88 次初始化占比很高，优化阶段很短，因此只适合作为软件和研究试跑。

VAE 训练 10 epochs、GP 12 steps；原 LSBO 使用 3 个分支、每分支 4 点、1 个 restart、8 个 raw samples、关闭额外局部分支优化。正式论文实验需要重新预注册更充分的训练和重复预算。

合成记录复用昂贵评估协议，其中 `mda_evaluated` 表示相应合成评价阶段已执行；本轮所有这些调用都是廉价数学函数，不是 RCAIDE。

## 结果

数值越小越好。仅在所有种子均找到可行解时计算平均最优目标；没有删除失败种子再求均值。

| 场景 | 方法 | 找到可行解的种子 | 平均最优目标 | 平均调用数 |
| --- | --- | ---: | ---: | ---: |
| mixed | RA-LSBO | 3/3 | 100.1091 | 106.67 |
| mixed | No boundary | 3/3 | 100.1608 | 104.00 |
| mixed | CBO | 3/3 | 100.0390 | 112.00 |
| mixed | Original LSBO | 3/3 | 100.0271 | 112.00 |
| mixed | Random | 3/3 | 100.2725 | 112.00 |
| sparse | RA-LSBO | 3/3 | 100.1035 | 112.00 |
| sparse | No boundary | 3/3 | 100.2879 | 107.33 |
| sparse | CBO | 3/3 | 100.0377 | 112.00 |
| sparse | Original LSBO | 3/3 | 100.0484 | 112.00 |
| sparse | Random | 3/3 | 100.4198 | 112.00 |
| no_initial_feasible | RA-LSBO | 2/3 | 不计算 | 96.00 |
| no_initial_feasible | No boundary | 2/3 | 不计算 | 96.00 |
| no_initial_feasible | CBO | 3/3 | 100.6099 | 112.00 |
| no_initial_feasible | Original LSBO | 3/3 | 100.0822 | 112.00 |
| no_initial_feasible | Random | 3/3 | 101.6150 | 112.00 |

结论是预算和停止语义可运行，但当前 RA 配置没有超过原 LSBO / CBO。边界机制在部分种子中缓解停滞，但还不是统计优势证据。无初始可行点时，8 次发现额度会在尚未稳定找到可行点前耗尽；这一失败被原样保留，未自动扩大预算。

mixed 的种子 0 在 8 次边界调用之后，没有满足开发门槛的候选，因此在 96 次总调用时停止。所有无初始可行场景的 RA 运行都在 96 次停止，原因是发现额度耗尽。报告保存每次选择原因、模式和预算占用，未将提前停止标为完成全部调用。

开发过程中较早的试跑目录仍保留。最终目录已修正随机基线混入局部采样的问题，并使选点排序保持在 Log-EI 域，避免指数下溢丢失候选次序。这是代码正确性修复，没有更改风险阈值、校准方法或实验预算来追求分数。
