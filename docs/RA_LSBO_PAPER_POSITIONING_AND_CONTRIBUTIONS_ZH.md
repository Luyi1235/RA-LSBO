# RA-LSBO 论文定位：回到“风险感知潜空间贝叶斯优化”

**结论先说：不需要给 RA-LSBO 另起一个新名字。** RA-LSBO 应保持其原有含义：

**Risk-Aware Latent-Space Bayesian Optimization（风险感知潜空间贝叶斯优化）。**

此前“基于 VAE 潜空间目标建模与显式变量约束建模”的说法确实讲窄了：它只描述了双视图代理模型，遗漏了 RA-LSBO 的风险感知决策；同时容易让人误以为 VAE 压缩了全部连续和离散设计变量。以下按仓库实际代码，重新界定论文口径。

## 1. 推荐论文题目

**中文：面向混合变量工程设计与部分观测约束的风险感知潜空间贝叶斯优化方法**

**英文：Risk-Aware Latent-Space Bayesian Optimization for Mixed-Variable Engineering Design with Hidden Evaluation Failures and Partially Observed Constraints**

一句话定义：

> RA-LSBO 面向昂贵的混合变量工程设计优化，利用结构化潜空间表示离散构型，分别建立目标性能与评价风险代理模型，并在约束反馈可能精确、区间化或缺失时，进行风险感知的可行解发现与性能改进。

这个题目直接保留 RA-LSBO 的四个核心：Risk-Aware、Latent-Space、Bayesian Optimization 和工程设计应用。

## 2. 潜空间到底表示什么？

当前方法的设计变量可以写成：

\[
\mathbf{x}=(\mathbf{x}_c,\mathbf{x}_d,\mathbf{m}),
\]

其中：
- \(\mathbf{x}_c\)：连续设计参数；
- \(\mathbf{x}_d\)：离散构型/架构选择；
- \(\mathbf{m}\)：由离散构型决定的条件激活掩码。

结构化 VAE 主要把离散构型及其条件激活关系编码为低维潜变量：

\[
\mathbf{z}=E_\phi(\mathbf{x}_d,\mathbf{m}).
\]

**连续设计变量并没有被整体压缩掉。** 连续变量仍以归一化后的活动坐标输入 GP，激活掩码也保留。潜空间的作用是让不同离散构型可以通过学习到的结构表示共享统计信息，而不是简单把整个设计向量变成一个黑箱低维码。

PR #45 的代码采用固定的 2,000 条合法离散构型语料训练结构表示；语料没有飞机评价标签，不调用物理模型。在线表示在预定前缀更新，GP 使用对应历史前缀的封存特征快照。

论文中应称为：

**“基于结构化 VAE 的离散构型潜空间表示”**，

不要写成“对全部混合设计变量进行 VAE 降维”。

对应代码：ra_lsbo/structure_corpus.py、ra_lsbo/structured_encoder.py、ra_lsbo/partial_bo/models.py、ra_lsbo/experiments/simplified_aircraft/corpus_optimizer.py。

## 3. RA-LSBO 的风险感知体现在哪里？

一次昂贵工程评价可能产生三类不同信息：
1. 评价正常完成，得到目标值；
2. 评价完成，但一个或多个工程约束违反；
3. 评价未完成，目标或部分约束没有可信结果。

基础设施错误和数值异常还必须与物理不可行区分。RA-LSBO 不应把这些情况统一转换成一个任意的大罚值。

PR #45 的双视图后验分别预测：
- 目标性能，例如任务能耗；
- 评价完成状态；
- 各项工程约束余量。

这意味着算法同时考虑“完成评价后性能有多好”和“这个候选是否可能完成评价、是否可能满足约束”。但当前主实验主要建模的是聚合的评价完成状态，**不能宣称五种具体物理失效机理都已被准确学习**。

## 4. 当前主方法的关键结构：目标–风险双视图代理模型

建议正式称为：

**目标性能与评价风险分视图代理建模（dual-view surrogate modeling for objective performance and evaluation risk）。**

目标 GP 使用潜空间特征：

\[
\mathbf{u}_f=[\widetilde{\mathbf{x}}_c,\mathbf{m},\mathbf{z}].
\]

评价完成状态和约束 GP 使用显式构型特征：

\[
\mathbf{u}_r=[\widetilde{\mathbf{x}}_c,\mathbf{m},
\operatorname{onehot}(\mathbf{x}_d),\mathbf{m}_d].
\]

也就是：
- 目标性能：活动连续变量 + 掩码 + 离散构型潜变量；
- 评价完成状态：活动连续变量 + 掩码 + 显式离散构型；
- 各约束响应：同样保留显式离散构型和激活关系。

为什么这样做？目标性能可能在不同构型之间呈现较平滑的关联，而可行性边界可能对离散架构切换和条件激活变量更加敏感。统一使用同一输入表示未必同时适合两类响应。

RA-LSBO 的核心假设是：**目标与风险响应具有不同的统计结构，因此可以采用不同的设计空间表征，再在同一个贝叶斯优化决策中协同使用。**

这是可被实验否证的研究假设，不是 VAE 或双视图实现本身自动证明的结论。

## 5. 部分观测约束如何处理？

当前观测接口区分：
- 精确值：\(y=y^*\)；
- 区间值：\(y\in[a,b]\)，包括单侧界；
- 缺失值：该输出没有可信信息，不向该输出 GP 填入伪标签。

精确观测采用 Gaussian likelihood；区间观测通过区间似然和 EP 近似后验；缺失输出不进入对应输出头的似然。评价完成状态另行建模。

这避免把未返回的约束误判为满足，也避免把某个阶段的求解失败伪装成最终物理约束违反。需要注意：GP、EP 和区间似然本身都有先例；论文贡献应放在它们与构型潜空间、显式风险视图及风险感知决策的具体协同方式，而不是声称首次提出 EP 或区间 GP。

## 6. 风险感知的候选选择

PR #45 主方法采用分阶段的约束贝叶斯优化逻辑：

**尚无可行设计时：** 以发现可行设计为优先，不使用没有可靠可行 incumbent 的普通 EI。

**已有可行设计后：** 将目标 EI 与评价完成概率、约束满足概率结合，推动可行域内的性能改善。

**边界探索与回退：** 按预设比例安排边界信息探索；若后验支持不足或 GP 数值拟合失败，则执行登记的构型覆盖回退，不伪造预测或标签。

概念上可写为：

\[
A(\mathbf{x})\approx EI(\mathbf{x})\,
P(C=1\mid\mathbf{x})\,
\prod_j P(g_j(\mathbf{x})\le0),
\]

但无可行 incumbent 时，算法转为可行性发现；边界探索也有独立的阶段规则。

**限制必须写清楚：** 约束概率乘积使用独立性近似，不是严格联合可行概率；当前概率和后验支持也不是安全保证或保守置信下界。

## 7. PR #45 七算法实验与 RA-LSBO 的真实对应关系

PR #45 的源码明确记录：实验显示名 ra_lsbo 是对既有 hybrid_onehot 源码的拟议比较身份，映射尚未被声明为最终科学资格认定。

| 实验方法名 | 实际含义 | 论文用途 |
|---|---|---|
| ra_lsbo | hybrid_onehot：目标潜空间，完成/约束显式 one-hot | 拟议 RA-LSBO 双视图主方法 |
| full_latent | 所有输出均用潜空间视图 | 全潜空间对照 |
| full_onehot | 所有输出均用显式 one-hot | 全显式表示对照 |
| reverse_representation | 目标显式、风险潜空间 | 反向双视图消融 |
| interval_as_missing | GP 训练时移除区间观测，保留原始物理记录和完成状态 | 区间反馈消融 |
| random | 合法候选池随机选择 | 随机参考 |
| cbob_adapted | 独立实现的 EICB/CBOB 思想适配 | 探索性外部对照，不是官方 CBOB |

还有一个必须避免的代码口径混淆：PR #45 实际运行的是 simplified-aircraft 的 dualview_optimizer / CorpusDiscoveryBO 路径，并不是直接调用旧版通用入口 ra_lsbo/optimizer.py 的 run_optimizer。仓库保留了多个研究阶段的实现。论文必须明确指定 PR #45 对应的双视图算法为被研究版本，不能把旧版 RF 风险头、sigmoid 校准、其他 SOC 控制分支全部拼成一个算法。

## 8. 哪些内容不能冒充当前核心创新？

- **SOC 在线自适应权重控制**：属于另一条后续研究分支，没有作为 PR #45 主方法运行；不应并入当前核心方法。
- **五种失效机理均已学会**：真实数据对部分类别缺少正例；当前主实验完成模型主要是聚合完成状态。
- **官方 CBOB 复现**：cbob_adapted 是独立 EICB 思想适配，不是作者原版代码或严格等价实现。
- **安全保证**：当前风险概率、EP 后验和边界分数不构成形式化安全保证。
- **高保真飞机验证**：PR #45 是简化飞机模型实验，不是 RCAIDE 高保真验证。

## 9. 从审稿人角度，真正可以主张的创新是什么？

建议将创新主张收敛为两项，第三项作为方法支撑：

**贡献一（主创新候选）：面向混合层级构型的目标–风险双视图潜空间贝叶斯优化。**  
不是简单“用了 VAE”，而是提出一种按响应类型分配输入表征的约束贝叶斯优化架构：性能响应利用构型潜空间，完成状态和工程约束保留显式构型信息，并在统一决策中协同使用。关键验证是它是否优于全潜空间、全 one-hot 和反向双视图。

**贡献二（观测建模贡献）：精确、区间和缺失约束反馈下的风险代理建模。**  
在不把未知值伪装成失败或满足的前提下，利用区间似然/EP 更新约束后验，并将评价完成状态与数值约束分开。关键验证是 interval_as_missing 消融，以及约束预测和可行解发现是否获得稳定收益。

**贡献三（优化机制支撑）：可行性发现与可行域内性能改进相结合的阶段化风险感知采集。**  
在没有可行 incumbent 时优先发现可行设计；有可行解后再开展 EI 驱动的性能优化，并按固定预算安排边界探索。它是完整算法不可缺少的部分，但其中 EI、概率门槛和边界探索均有先例，不能单独宣称为全新理论。

## 10. 已完成与仍需完成

已完成：
- 结构化离散构型 VAE、2,000 条无标签构型语料及固定更新/快照机制；
- 目标潜空间、风险显式构型的双视图代理实现；
- 精确/区间/缺失观测的 GP/EP 建模接口；
- 完成状态、各约束后验和分阶段采集/回退机制；
- PR #45 两任务七方法大规模简化飞机计算：2,048 个任务–种子组、151,006 次真实简化飞机调用，全部完成并结算。

仍需完成：
1. PR #46 的独立事后审计、24,576 个共享初始样本的原始可行率和主算法配对统计；
2. 证明 140 km 任务在预先定义的抽样分布下确实是稀疏可行域；
3. 完成 RA-LSBO、全潜空间、全 one-hot、反向双视图和区间反馈消融的公平配对解释；
4. 冻结 PR #45 中 ra_lsbo 显示名与 hybrid_onehot 源码之间的正式算法定义，避免论文标签和实现身份不一致；
5. 资格成立后再做独立种子确认、强约束 BO 基线比较；若论文强调工程高保真，再补 RCAIDE 验证；
6. 公开完整可复现材料，并如实报告简化模型、变量规模、物理假设和所有负结果。

当前 151,006 次计算证明了工程运行规模，不等于算法优越性已被证明。PR #45 的主方法均值与 Full Latent 很接近，最终论文必须依赖配对差值、置信区间和机制消融，而不能只用总调用数证明创新。

## 11. 最终建议

论文名称继续用 **RA-LSBO：风险感知潜空间贝叶斯优化**。不要把 H1/H2 等内部研发代号放进论文。正式方法名称建议统一为：

**RA-LSBO（dual-view latent-objective / explicit-risk constrained Bayesian optimization）**，中文可写：

**“基于构型潜空间与显式风险视图的风险感知贝叶斯优化方法”。**

这既没有脱离 RA-LSBO，也准确描述了 PR #45 实际验证的算法。SOC 在线自适应权重、其他风险控制器和独立 CBOB 适配应作为单独扩展或对照，只有在独立实现和实验验证后才纳入主算法。
