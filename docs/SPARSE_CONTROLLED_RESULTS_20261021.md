# 稀疏可行域内部失效：补充受控验证

本案例在首个受控结果之后提出，方程、预算和算法在本案例采样前冻结。
它是单独的补充检验，不替换前一案例，也不作为真实飞机证据。
新增真实MDA为0。物理实验此时仍在执行，不能提前使用其结果。

## 设置与独立核验

保留串行五机制及层级变量，将显式可行椭圆半轴改为0.12、0.15，
并在(0.78, 0.69)附近加入半径0.055的任务失效区域，覆盖显式可行域内的
低目标区域。所有失败均按实际执行顺序删失后续标签。具体协议和代码
分别见 `SPARSE_CONTROLLED_PROTOCOL_20261021.md` 和 `ra_lsbo/controlled_sparse.py`。

独立的10,000点分层变量随机抽样，在通过packing预检后得到502个可行点，
即该抽样分布下可行率5.02%。这是受控案例的条件抽样结果，不能用于估计
飞机全设计空间的可行体积。

八方法、种子31/32/33，每种子共享900个初始点，RA按600训练、300校准划分。
每运行最多16个新调用，失败停止上限6；实际执行272个新受控调用。
独立审计核验14,200个抽样/静态/初始标签、24个运行的实际输出和账本。
60次模型拟合、228条选点预测、1,800条静态预测均从历史前缀和checkpoint重建通过。
原LSBO额外从初始状态重放23个提案，离散构型、来源、阶段一致，
归一化连续坐标误差不超过1e-8；没有重新求解物理问题。

静态600点训练集的五机制正例分别为57、26、31、85、81，均有实际训练监督。
这些数据与模型不进入飞机训练集。

最终可行性在600点独立测试段的校准Brier为：完整RA 0.00606980、
去机制0.00606980、one-hot 0.00568937。隐藏成功分别为0.03343428、
0.03343428、0.02670474。不能把测试集合成标签解释成飞机校准证据。

完整RA在种子33第4次调用得到改进；CBO在该种子实际6次调用内没有改进。
种子31、32完整RA均为零改进；种子31随机基线获得改进。报告保留这些结果，
并另按每对方法较小的实际调用数比较，不延长提前停止曲线。

## 可支持的结论

本案例中，经验校准和审批策略减少了高风险区域的连续失败调用。
完整RA并未优于去机制，潜空间风险表示也未优于one-hot；
去边界版本获得更多可行点，目标改进相同。因此仍不支持
“机制分解、新潜空间、校准和边界采样的组合稳定优于各消融”。

完整RA三次运行合计风险记账约8.45，但实际有14次未确认可行调用，
再次说明经验概率记账不是实际失败数的安全上界。确定性失败停止上限
与经验风险额度分别报告，不能混为概率覆盖保证。

三种子来自同一受控任务；900点热启动和16次短程优化不支持跨任务泛化结论。
去机制同时移除了总体隐藏成功项，不能单独识别五个分类头的因果收益。
随机基线沿用共同候选池的首个合法点，不是独立均匀设计空间随机优化。
