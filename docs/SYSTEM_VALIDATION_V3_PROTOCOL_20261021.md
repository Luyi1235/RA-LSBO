# 机制正例定向补采修订

本修订发生在任何真实优化对照启动之前。v2 前 48 个探测仅找到两个任务求解不收敛正例，低于原始分类头每类至少 3 个样本的既有拟合门槛，亦未达到原定 20 正/20 负训练支持标志。继续以全域随机补采为主，不能保证机制头能在完整系统检验中实际参与计算。按用户补齐训练数据的目标，改为利用已观察失效进行定向补采。

v2 已设置停止标记；在途点完成并计费，原计划、数据、零调用优化运行和独立审计保留。所有版本完整真实上限仍为 **480 = 最多120探测（含全部已执行）+72新校准+8方法×3种子×12优化**。不因更换版本扩充预算；本修订不改变物理后端、变量、算法、种子、模型、风险门槛或校准隔离。

## 合法失效邻域

只使用 v2 终止并审计后、当前物理契约下已真实观察到的任务求解不收敛设计作为锚点，不使用旧物理版本标签。冻结剩余探测候选直到完整探测列表共120点。候选在锚点的连续变量单位坐标上加入有界均匀扰动，半径固定为0.002、0.01、0.03、0.06，轮换锚点和半径，离散构型不变，投影到原合法单位盒后进行原廉价预检、物理规范化去重。每个候选保存锚点、半径、来源和真实输入，不注入故障、不修改求解器。

新邻域列表必须在任何邻域结果产生前冻结，段内不根据新结果改变候选或半径。每批4个。原历史与全部已完成探测中的任务不收敛正例达到20且负例达到20时停止补采，否则执行到完整探测120点上限。首次未知/基础设施错误停止后续提交，已在途完成并计费，无重试或填补。几何、网络、电机和能量审计没有正例时继续报告不充分，不借任务失败补它们的标签。

定向补采改变了训练分布，不能把其失败比例当作全域故障率。相邻设计是不同物理输入，但相关性高；20个正例只是原定支持标志，不代表20个独立失效区域或已保证泛化。报告锚点数量、各半径、每机制正负及未知数。

## 保持的后续验证

补采结束后，依照冻结的v2方法从原历史与实际探测拟合规划模型，冻结72个全新校准点，三层各24个。所有新校准标签在规划时尚未产生；拟合过程中不增加MDA。校准段完成后使用原八方法、31/32/33种子、每运行12次上限进行真实对照。RA的初次训练包含全部探测，最近72条仅用于校准。各方法只加入自身后续新结果，不共享其他方法的未来真值。

受控部分继续继承原24个运行及独立静态留出。没有观察真实优化效果后改算法、换种子或重跑。最终比较保留所有早停，在相同实际调用数处另作配对比较，并披露原420次历史和所有版本新增费用。

最终审计逐一核对唯一账本、此前各版本已收费调用、冻结邻域与实际请求、合法坐标距离、原始响应、训练/校准来源、编码器及校准身份。补采数据和实验后汇总模型单独交付，不把汇总模型的拟合程度当作本轮前瞻效果。
