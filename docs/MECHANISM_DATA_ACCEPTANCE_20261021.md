# 机制数据与系统效果的验收口径

本文解释结果判定，不改变冻结实验的候选、算法、额度或停止规则。

“模块能运行”“分类头能拟合”“有足够泛化证据”和“提高优化效率”是四个不同结论。
不能用前一项代替后一项。

## 实际训练支持

每个隐藏机制分别统计已观察正例、负例和未知，不能把未知当负例。真实飞机、
受控串行问题、不同物理契约的历史分别统计。任务内部的残差求解次数不是新的MDA次数。
廉价预检排除的构型不能作为“通过预检后的昂贵隐藏失败”的正例。

当前RF最低每类3个样本才能拟合；20正/20负只是冻结补采的支持标志。
二者均不是“数据充分”的统计保证。局部邻域中的多个点不能算多个独立失效区域。
没有真实正例的头继续保持不可用，不能宣称五类机制均完成真实训练。

## 原始输出与部分观测

优先使用原始请求、原始响应、明确阶段、异常来源和输出有效性证据。
有效能耗、缺失约束和未知可行性可以同时存在。不能把升力代理无法定义，
直接改写成一个虚构的失速余量；也不能把所有一般性程序异常当成设计失效。
任何重注释须保留原记录、原账本及独立的规则版本，并可从原始响应重建。

## 预测、校准与区域迁移

训练时同时约束编码器、目标/约束GP、风险头的历史范围。校准另用后续时间段，
不先用全量历史训练特征再声称早期预测无泄漏。

当前经验sigmoid校准最低30个有效标签、每类5个、3种不同评分，并要求正斜率；
不足则记录降级。拟合校准器不是可靠性或安全覆盖证明，不能在同一拟合段上
展示校准后Brier就当作独立效果。

留一失效区域诊断必须同时移除锚点及其全部已生成邻居。本轮诊断只覆盖预定义的
两个探测锚点族，不使用新校准中另外观察到的失败构型，也不能把定向样本的
故障率当作全域频率。该诊断是实验后探索，不用于调整
已冻结的优化器。若留出区域的失败召回仍低，即使训练正例达标，也不判为泛化充分。

## 完整系统效果

保留所有方法、种子、零改进和提前停止。共享补采与校准带来的改进不能归给某个
优化算法；继承的历史最优值也不是新增收益。按相同实际调用数比较，未运行的调用
不能用持平曲线补足。MDA费用包含失败、未知和在途调用，所有方案版本合计计费。

完整RA与CBO、原LSBO和消融做配对比较。三种子、单任务、12次短程热启动实验
是本任务的有限效果验证，不能直接支持跨任务“稳定领先”。去机制版本同时移除了
总体隐藏成功项，需另查单独机制头是否提供额外信息；仅有一种真实隐藏失败时，
其标签可能与总体隐藏成功完全互补，不能据此证明多机制分解的价值。

未校准版本保留相同原始训练前缀，但采用原始风险加权EI、每次完整
风险扣减及基线选点模式；它不是仅替换sigmoid数值而其他操作规则
完全相同的试验。完整RA与该版本的差异需解释成校准及其关联决策策略
的操作性消融，不能把全部收益直接归因于概率数值校准本身。

本轮72条滚动留出窗口大于12次新增调用上限。使用该窗口的RA方法
在短程中更新原始编码器/GP/RF时，训练前缀吸收的是较早校准记录，
新优化标签尚未移出留出窗口。新结果仍经最优可行值、已评估集合和
候选池的精英局部中心影响选点；不能描述成新优化标签已立即更新GP。
CBO可使用全部已知记录，这个训练信息分配差异必须随对照结果披露。
本轮没有为改善结果而改变已经冻结的窗口、训练范围或算法参数。

当前飞机工程分支是14连续、5离散变量；不是新版论文24变量的复现实验。
数值MDA的可行结论依赖冻结物理模型及其概念设计近似，不等于飞行试验验证。
