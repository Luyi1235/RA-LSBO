# PR52：PR45 原生在线候选的逐轮风险预测审计（零物理/GP/VAE 拟合）

## 依据

PR50 全库核查显示：评价状态完成头在 151006 次记录上恒为 1，而 34675 次任务因 SOC 约束提前中止。PR51 的跨种子 qA 训练集在 96–192 条时 One-hot 风险视图较好，但原来的在线算法只有每个种子 12 个共享初值、18 次在线评价。不能将 n=192 的回顾性预测视为原算法同预算性能，也不能把 qA 校准直接视为对主动选点已校准。

本次直接读取 **PR45 原始 proposals.jsonl** 的提案前概率及候选索引，与原始 SQLite 中**同一设计**的后验真实评价配对。不重新训练任何模型。提案前缀与原始 12 个共享初值加前序真实在线评价逐次哈希对齐；每个提案都与原始 settle call ticket、记录 hash、物理契约、候选 ID 对齐。原数据库通过 SQLite mode=ro 读取，运行前后比较 SHA256 和修改时间；不修改 PR45/PR46/PR48/PR49/PR50/PR51 的代码及证据。

## 固定比较范围与有效性

- 两任务（100 km / 140 km）；**仅两个原始主臂** ra_lsbo（目标 latent、风险 One-hot）与 full_latent。不同臂各自选点不同，因此不能把跨臂误差差别当作同点表示因果效应。
- 默认每任务 64 个校准种子（原种子索引 640–703）及独立 64 个测试种子（704–767），与 PR48/49/51 的机制测试种子不同；无 outcome 筛选。共审计 9216 个原始在线 selected calls（含无预测覆盖步骤）。--per-block 1 只作 smoke。
- 读取原生已记录 completion、各约束及联合独立性代理概率；以 PR50 真值分别评分真实任务完成、已知可用可行设计。对比「不乘旧 status 因子的全约束概率」、「PR45 原始 completion×constraint」、「SOC 对任务完成的代理」、「旧记录完成概率对任务完成的错误解释」。
- coverage / 数值失败回退若没有模型预测，不伪造风险概率，也不排除这些评价费用；统计其调用数及真实可行比例，单独提供模型覆盖率。
- 两个种子块完全分离；对每任务/方法/代理在**校准种子**上仅拟合一个正则化 logit 截距，在**测试种子**上评估 raw 与 posthoc calibrated；无测试标签泄漏。此截距利用了其他种子的在线结果，**从未提供给 PR45 原在线选点算法**。
- 还与真正仅依赖该原始在线方法历史前缀的 Laplace 可行率基线比较。报告 Brier / log loss / ECE、p≥0.8 时在**原方法已选中样本上的**假可行次数、平均预测失败费用与真实失败次数；平均配对 Brier 差区间按测试种子聚类（描述性）。
- 当前线上采集函数没有被改变：所有阈值与风险费用均为**事后观察诊断**，绝不能解释为“换用门槛将选择哪个未评价候选”，更不能证明安全或因果优化收益。
- 140 km 任务的独立稀疏资格仍未建立，所有结果是简化飞机模型的探索性研究。
