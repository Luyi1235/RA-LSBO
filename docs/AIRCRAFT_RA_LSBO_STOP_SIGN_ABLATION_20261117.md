# RA-LSBO 冷启动的中止约束信息粒度消融

PR119 在两个降阶飞机工况观察到，保留已知中止返回的工程约束观测，可减少初始无解时找到首个可用设计所需的评价数。本轮用新种子复验该效果，并测量仅使用通过或违反方向时的增益。PR119 固定结果为 0364d5ae91ef556f3e9f8935b6369285dfa803f6。

| 方法 | 已知中止时返回的非解析约束监督 |
| --- | --- |
| ra_to_lsbo | 保留返回的精确值与区间 |
| ra_stop_sign_to_lsbo | 精确值与区间均压缩为可确定的通过或违反方向 |
| ra_stop_status_to_lsbo | 将返回的非解析约束观测标作缺失 |

通过保留为 \(g\le 0\)，违反保留为 \(g>0\)。区间跨越判定界且无法确定方向时，在方向臂中标作缺失。三臂共享完成状态标签、已完成评价的约束、解析约束、目标观测、原始历史和表示训练。三臂采用同一套独立代理模型训练流程、覆盖规则和 20% 的计划边界信息评分。首次观测到可用设计后，接下来的建议由原版 LSBO 根据原始历史生成。

两工况分别为 4 m/s 逆风及无风增载 24 kg，任务 140 km，积分步长 20 s。每工况使用 40 个新种子，三臂共享 4 个初始设计与 128 个冷启动候选。每臂最多 20 次在线评价。Smoke 使用 PR119 的两个已知种子，覆盖初始有解与初始无解路径。

## 终点与判定

主比较为方向臂减遮蔽臂。纳入初始无解的种子，以首个可用设计的在线调用序号计分，20 次内未找到计 21。按工况报告种子内差的均值和 95% 配对 bootstrap 区间。两个工况的区间上界均小于 0 时，支持方向观测在这两个工况减少冷启动所需评价次数。

次要比较包括全量臂减遮蔽臂，以复验 PR119，以及方向臂减全量臂，以衡量压缩信息后的变化。只有方向臂满足主比较，且方向减全量在两工况的区间上界均不超过预设的 1 次评价，才称方向观测在此容忍线内保留了实用收益。另报 20 次内发现率、终点可用性优先的胜负平及双方均有解条件下的能耗差。

## 证据验收

校验器由原始账本重建三种 GP 训练视图，核对训练前缀摘要，记录实际使用方向观测的拟合步数及无可判定方向的拟合步数。首个决策与初始有解种子的完整原版 LSBO 轨迹要在三臂匹配。分析报告输出 primary、comparisons、full_evidence_replication、stop_evidence_steps 和逐种子轨迹。

| 配置 | 共享初始 + 在线 | 总降阶调用 |
| --- | ---: | ---: |
| stop-signs-smoke | 8 + 36 | 44 |
| stop-signs-headwind | 160 + 2400 | 2560 |
| stop-signs-payload | 160 + 2400 | 2560 |

正式实验共 5120 次降阶评价，RCAIDE/MDA 调用为 0。使用 Rcaide_vsp 的 Python 3.9.25 和 `run_aircraft_ra_lsbo_comparison.py` 执行 plan、run、verify。分析和日志输出放在各账本目录之外，和原始账本及相对路径的 SHA256SUMS.txt 一起上传。
