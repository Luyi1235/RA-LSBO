# 冻结模型跨搜索策略验证协议

协议记录于首次运行本轮跨策略评分之前。只使用 2026-10-12 对比组中已完成的五个运行；它们共享完全一致的保存物理契约。目录位于 `LSBO/X57-LSBO-refactored/runs/comparison_300/comparison_20261012_201305_7d302a67`。

固定进行两组检查：分别以 LSBO、Random 的历史为拟合来源。每组使用前 180 条训练表示和分类头，接下来 60 条校准，最后 60 条作同运行留出；其余四种方法的历史作为跨策略测试。不是选择评分最好的一组报告。

采用现有 4 维结构化潜变量、60 epochs、64 棵树、seed=0、默认 sigmoid 校准门槛和固定开发阈值 0.8。不改变 VAE 损失、分类器参数、概率门槛或物理配置。校准前排除训练中出现过的物理设计及校准段内重复设计；每个测试组排除整个前 240 条中出现过的设计及组内重复设计。规范化包含非激活变量归一，连续量不做近邻合并。

完整保存预测后才附加真值。模型不使用目标运行的标签或目标留出样本训练。按每个测试运行分别报告 Brier、log loss、ECE、校准启用状态和达到 0.8 门槛的实际样本结果，不汇总为“独立重复”的均值或显著性检验。同一源模型的测试组之间可能共享设计，须记录交集。

这些运行均使用 seed=0 和共享初始化。去重不消除近邻相关性，也不使自适应历史变成独立随机样本。本检查仅检验历史搜索分布之间的概率迁移；不是新 MDA 优化试验，不证明 RA-LSBO 的优化收益或风险上界。

该对比组审计结果没有隐藏失效正样本。隐藏机制头应降级，不能通过合并其他物理契约中的失败来补齐类别。最终可行性头主要学习显式工程约束违规。
