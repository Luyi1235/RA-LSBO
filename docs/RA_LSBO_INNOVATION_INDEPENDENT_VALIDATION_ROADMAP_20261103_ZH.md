# RA-LSBO 论文创新与独立验证路线报告

日期：2026-11-03。深化 PR #35，不重复 P0–P6 证据账本；仅为方案，非已完成或已授权实验。本轮飞机、RCAIDE 调用均为 0。文献检索不是系统综述或专利检索，候选创新不保证首创。

## 一、候选与推荐

推荐主线是**输出与证据敏感的层级表征和约束决策**：目标与约束使用可区别的结构表征，按各输出的真实证据类型建模并审计决策。第二候选是**预序贯、部分证据驱动的 SOC 双视图决策**：预测先提交、真实反馈结算后更新有界权重，区分候选生成和最终排序。H1/H2 为原型，不等于创新已验证。GP、EP、VAE、区间似然、模型融合、局部搜索均已有文献，不单独声称原创。

风险首先指模型预测的完成/约束事件和真实评价失败，不等同事故概率或适航安全。扰动分布尚无经验校准，不宣称机会约束、CVaR 或安全保证。P3 动态调权结果混合；P6 仅 2/16 组可识别，两例局部生成改变选点、最终排序条件对照未变，14/16 近并列，历史 SLSQP 内部轨迹缺失。这不能证明整条轨迹因果作用或能耗改善。

## 二、候选一：表征与证据

合法设计为 \(x=(a,u_{A(a)})\)：离散构型 \(a\)、活跃集合 \(A(a)\)、掩码 \(m(a)\)；规范化不活跃项以避免同一物理设计重复编码。历史 \(D_t=\{(x_i,e_{ij})\}_{i\le t,j}\)，每个输出证据 \(e_{ij}\) 标记 exact、interval、sign 或 missing，附阶段、单位、可信状态；未知/求解失败/未执行不等于违反。

为输出 \(j\) 指定前缀可用的 \(\phi_{j,t}\)，用相应证据似然拟合 \(p_j(y_j\mid\phi_{j,t}(x),D_t)\)。候选实现：目标 \(\phi_f=z_t(x)\)，完成状态与约束 \(\phi_g=h(x)\)，其中 \(z_t\) 是登记训练规则的结构潜表征，\(h\) 是含类别/活跃掩码的显式层级表征。编码器身份、样本来源和训练费用须记录；结构样本不是物理标签。

输入为合法域、结算历史、证据及预算；输出为下一合法候选、逐输出预测、采集分数和审计记录。步骤：规范化设计；仅用历史构造表征与各响应头；在统一候选域按冻结的探索/约束/目标规则选点并可局部优化；提交预测；真实调用结算后才扩充历史。\(P(C,\cap_j\{g_j\le0\}\mid x,D_t)\) 是目标事件而非安全保证；若使用边缘概率乘积，须声明独立性近似，不能写成一般恒等式。

**文献区别。** CBOB 已有部分观测和异质似然；混合 GP、层级架构优化已有类别、掩码及潜映射；联合降维 CBO 已存在。可检验的组合贡献是：对不同输出分配层级视图，同时保留输出级部分证据，并在同信息、预算及搜索下证明价值；不能声称首个潜空间或删失 CBO。

**假设与消融。** 独立资格任务上，目标潜空间+约束显式表征比全潜表征更容易在固定预算发现完整名义可行解，普通任务不能掩盖明显退化。必要消融：混合、全潜、全显式、目标显式/约束潜；区间似然对比将区间设为 missing；必要时固定/重训编码器。冻结其余搜索、GP、初始化，不能伪造精确值；记录参数量和训练时间。全 one-hot、随机及强外部基线另作对照。

**成功与否定。** 主要比较是两任务混合对全潜的配对可行率差；140 km 估计绝对改善至少 0.15 且两任务多重性控制后通过优势检验。100 km 单独报告，建议不劣界 -0.10，但须另算功效，不能把不显著当不劣。若区间整体低于 0.15 则否定预设工程价值；若跨越 0 和 0.15 则证据不足。控制搜索与费用后优势消失，不支持表征贡献。独立预提交预测面板须分开报告 exact NLL、interval NLL、已知标签 Brier。

## 三、候选二：结算后 SOC 双视图

同一历史和候选的显式视图 \(O\)、潜视图 \(L\) 给出 SOC 约束分布 \(F_O,F_L\)。混合 \(F=wF_O+(1-w)F_L\)，可行概率为 \(wF_O(0)+(1-w)F_L(0)\)，不是单高斯近似后的 CDF，也不是经校准风险上界。输入输出同候选一，另记录预测承诺、得分、裁剪量、权重和事件链。

选点前提交两组预测；结算 exact 时 \(\ell=-\log[\phi((y-\mu)/\sigma)/\sigma]\)，interval 时 \(\ell=-\log[\Phi((u-\mu)/\sigma)-\Phi((l-\mu)/\sigma)]\)。缺失/未拟合不伪造评分。历史 H2 原型 \(S_n=\sum_i\operatorname{clip}(\ell_{L,i}-\ell_{O,i},-4,4)\)，前四次有效配对评分前 \(w=0.5\)，之后 \(w=\operatorname{clip}_{[0.1,0.9]}\{\operatorname{logistic}(0.35S_n/\sqrt n)\}\)。不同类型原始 NLL 不合并均值；成对差只在同一事件、同一证据类型内计算。此规则不是最优性或收敛保证。

**假设和判据。** 相同模型、预算及搜索下，动态权重相比固定 0.5 改善独立 SOC 成对预测，且改善闭环可行发现或预定义联合决策效用。消融固定 0.5、单视图、关闭更新但保留费用、exact/interval 分类型以及生成/排序交叉干预。先冻结独立面板样本量和最小收益，按种子/任务聚类，再独立闭环比较。若区间排除预定收益、动态不优或费用抵消收益则否定价值；样本不足保留不确定，不能以选点改变冒充成功。

## 四、文献与强外部基线

共享合法域、初始化、证据可见性和真实评价预算；可以声明内部忽略的信息，不得补造真值。开销是需实测的项目，非未经测量的时间。

| 方法 | 问题与混合变量 | 部分反馈、约束及采集 | 费用与复现资格 |
|---|---|---|---|
| CBOB [1] | 连续约束 BO；层级混合需适配 | 数值/不等式部分观测、异质 GP/EP 和 EICB；未知不等于违反 | 已有原文/参考源码，同接口飞机适配未验证；验收似然、尺度及选点后称 CBOB-adapted；计 GP/EP 和搜索时间。 |
| SCBO [2] | 连续信赖域；类别和激活需适配 | 约束 Thompson 采样、信赖域；删失/隐藏失败另定义 | 本项目 `scbo_adapted` 伯努利可行采样明确不同于原版；须核验官方实现、改动和费用。 |
| SEGO-UTB [3] | 混合约束飞机设计 | 上界可行准则与 EI；中止语义另定义 | 本项目 `sego_utb_adapted` 使用固定 1.96 等，不是完整复现；代码许可和逐项算法验收待办。 |
| 混合 GP/层级架构 [4–7] | 类别潜映射、混合核、条件激活 | 普通混合 GP 不自动处理区间或隐藏失败，须另配采集 | 可作结构核对照，不自动构成 BO 基线；许可、核训练、反馈适配待验证。 |
| 飞机 hidden constraints [8] | 飞机隐藏约束 | 求解失败与 SOC 区间不同 | 代码、任务及许可待核验，不能假定可运行。 |
| AE 约束 BO [9] | 目标/约束联合降维 | 不自动满足本项目删失及采集契约 | 是创新性近邻；移植须统一信息、实现并计费。 |
| random、onehot、全潜、H1/H2 | 项目已有具体实现 | 同样可见标签，记录实际使用情况 | 可作为待新协议资格的内部/随机对照，不是已认证外部强基线。 |

现有 `logcei`、`scbo_adapted`、`sego_utb_adapted` 不可冒充官方方法。正式实验前需零真值接口测试、独立开发资格以及源码/许可/超参数冻结。优先验收 CBOB-adapted；无法忠实适配则强基线缺口为阻塞，不能更名或看结果后挑弱对照。

## 五、独立资格与性能确认

### 稀疏定义

先冻结 100/140 km 源码、任务、20 秒数值设置、设计边界及阈值，`sparse` 只是历史名字。定义分布：从合法完整离散构型表等概率有放回抽取，在活跃连续域独立均匀抽样，规范化不活跃项；对确定性 `span`/`packing` 解析拒绝，保留拒绝数，得到 \(q_A\)。预登记构型表、生成器版本和每构型比例；不将 LHS/Sobol 当独立二项抽样。

\(p_A=P_{q_A}(完成且全部真实约束满足)\)。用新随机流建议 21001/21002，每任务各抽 300 个独立样本并评价。若 140 km 双侧 95% Clopper–Pearson 上界 <0.10 且至少一个真实可行设计，才称该分布下稀疏；100 km 下界 >0.20 才称较宽。阈值是工程建议而非文献标准；两任务区间不自动具有联合 95% 覆盖。跨阈值或无可行设计则不通过/尚不确定，不换任务或反复抽样。

中止证据仅在严格证明违反时记已知不可行；其他 unknown 报 \([k/300,(k+u)/300]\) 识别界并停止，不删未知。解析筛选不收费但记录；真实调用全部计费，异常不自动重试。资格标签不复用为优化初值。

### 样本量与分析

资格和基线验收后，每任务 192 个新种子（建议 22001–22192；每任务派生独立 RNG 子流）。每任务/种子 12 个真实共享初值；五方法各在线 18 次：混合、全潜、全 one-hot、random、预验收 CBOB-adapted；每法最多一次 5 秒同设计复核且不回灌。每法名义优化预算 30（12+18），共享初值实际仅支付一次；复核额外收费，不是 RCAIDE 验证。

主比较仅为两任务混合 vs 全潜最终可行发现；Holm 控制两任务家族 0.05，配对二元精确 McNemar 报 n01/n10、差值及区间。其他对照为预指定重要次要比较，推断须另定多重性家族。规划配对差 0.15、不一致概率 0.40，即两个方向概率 0.275 和 0.125；192 对、每项双侧 alpha 0.025 的条件二项精确检验，方向正确且拒绝的功效约 84.1%。是规划假设而非实测效应；条件改变须在揭盲前重审，不可按结果补种子。100 km 的 -0.10 不劣需单独算功效。

首次可行计入共享初值，未发现于名义第 30 次右删失。报告 Kaplan–Meier、30 次截断限制均值及按种子配对 bootstrap 区间。只对有可行解的组比较能耗有选择偏差，应另报共同可行子集描述及预定义“任何可行解优于未找到可行解”的联合排序，不捏造失败能耗。分报完成/未知/不可行及所有种子；GP、编码器、选点、模型评价 CPU/墙钟分别计量。统计单位是种子，不是迭代或候选。

## 六、RCAIDE 映射

可映射仅指可定义物理量，并非接口已验证。本机只读检查定位 RCAIDE 包，`VERSION` 为 1.2.1，存在 `rcaide_leads-1.2.1.dist-info` 和电动推进/电池源码；`pip show RCAIDE` 无同名发行包。未导入求解器或运行仿真，不证明物理模型可运行。后续须核验来源、元数据、许可、OpenVSP、依赖、平台和哈希。

| 简化模型 | RCAIDE 拟映射 | 状态/缺口 |
|---|---|---|
| 翼尖/分布式布局、推进器 2/4/6 | 数量、位置、构型 | 需验证分支、安装、电网与气动干扰；不支持分支不进共同域。 |
| 机翼面积 10–18 m²、展弦比 7.5–13.5、翼展 | 机翼几何 | 量可定义；翼型、扭转、后掠和质量假设待冻结。 |
| 条件螺旋桨直径、间距、packing/span | 半径、坐标、几何检查 | 间距转换和 packing 含义未核验。 |
| 电池 128 串、并联 32/40/48 | 电芯/模组、电压、容量、质量 | 简化电芯 0.048 kg、质量分数 0.75；模组、曲线、管理系统和双重计重待核验。 |
| 固定质量、翼面积质量、载荷 | 起飞与部件质量 | 质量闭合未对齐，须统一边界并列差额。 |
| 100/140 km、44–58 m/s、爬升/巡航/储备、初始 SOC 0.95 | 航段和段间状态 | 距离、储备、高度环境及 SOC 传递待实现验证。 |
| 能耗 Wh | 电池端/推进端 J/Wh | 端口、效率、附件和损耗未对齐前不能比较相对误差。 |
| `g_soc=0.2-SOC_final` 和中止证据 | 初值、终态、储备 | 中止不能假定终态，须保留实际证据类型。 |
| stall、root bending、current、voltage、power | 气动、结构和电气状态/限值 | 同义输出和阈值未证实；结构、温度、推进干扰不能假定支持。 |
| 风、载荷、容量保持率 | 固定情景 | 筛选假设，非经验概率分布。 |

未来先零调用冻结包来源/哈希、环境、OpenVSP、构型、求解器、线程和单位/异常契约。另申请最多 48 次 RCAIDE：8 次接口/已知工况资格，32 次独立设计（每任务 16，预先按构型/边界分层而不按误差挑选），最多 8 次同设计数值分辨率复核。全部计费，失败不重试，名单先冻结，结果不回灌优化。无共同构型或约束无法对应即停止。报告同边界设计的能耗绝对/相对误差（分母接近零不用相对误差）、SOC 差、各映射约束符号混淆矩阵、失败/未知和分层样本数；重复复核不是独立设计。RCAIDE 是另一工程模型而非飞行真值，少样本不证明多保真 BO 或适航安全。

## 七、阻塞和决策

优先冻结候选一、强外部基线、任务资格及独立预测面板；候选二单独验证。主要阻塞包括外部基线可信实现、稀疏资格、确认样本/成本、RCAIDE 构型/质量/电池/任务/约束端到端映射。条件不满足时应缩小主张或报告负结果。
