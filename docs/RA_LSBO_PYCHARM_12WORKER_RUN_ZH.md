# RA-LSBO 12 进程入口：当前仅限零调用

**本版本不是完整的正式实验系统。** 真正的七种方法、正式批准凭据校验、共享真实初值、真实飞机调用适配、生产级原子账本与完整科学审计尚未交付。`execute` 无条件拒绝，不能通过修改参数绕过；既有历史 P0–P6 和资格计划没有改变。

在 PyCharm 打开本工作树，选择已存在的 `Rcaide_vsp` 解释器，右键根目录 `run_ra_lsbo_confirm_12workers.py` 运行。默认只打印零调用检查和缺失条件。无须 PowerShell；脚本自动确定项目路径。Python 使用 Windows spawn 和 `freeze_support()`，默认 12 工作进程，仅限模拟。

如需运行合成闭环，在 PyCharm Run/Debug Configurations 的 Script parameters 填写 `--mode simulate --output <从未存在的新目录>`。每任务一组模拟种子，七种名称仅为测试标签，不代表真实算法。模拟共 290 次合成调用：24 共享初值、252 在线、14 复核。目录内 SQLite 账本逐笔记录 started/settled 和哈希；结果按任务、种子、方法隔离，审计核对调用、共享记录、单臂历史和摘要。模型调用、RCAIDE 均为 0。`--mode status --output <已有模拟目录>` 重新只读审计。

失败时保留目录、账本和 error.txt；不自动续跑。模拟超时仅阻止继续派发新的试验，已派发进程安全退出，不能当作正式硬实时保障。模拟事务及证据不是已认证的真实飞机调用账本。正式批准前必须另行完成不可变确认计划、全量独立种子审核、七算法适配及独立资格、风险和数值契约、真实初值共享/预算并发校验、unknown 与中断账本、12 进程真实工作负载资源门限、审批凭证绑定和独立审计。禁止把模拟结果当成确认性实验。
