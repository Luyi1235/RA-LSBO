# PR62 | RA-LSBO 风险研究阶段性证据收束与论文定位

> 研究里程碑：2026-11-06。本文只归档、比较与解释既有真实实验和只读审计，不改变既有 GP/VAE、选择策略、风险语义、优化轨迹、结果分支及物理评价记录。无新增解析、飞机、RCAIDE、GP/VAE 拟合。

## 1. 执行摘要

**主判断：当前 RA-LSBO 不能被写作已经证明优于对照、具备安全保证的风险感知优化算法。** 同时，现有研究已经产生一条可追溯且有方法学价值的证据链：目标事件语义错误 → 稀疏/在线选点风险概率失准 → 未校准硬性风险门的候选饱和与高失败回退 → 单纯增加分支经验风险下限反而破坏等成本性能。

现阶段不应继续微调 Beta 系数、重新运行已看过结果的种子或将受风险阈值影响的选择结果当作概率校准证明。**将原风险预算与 branch_mean / branch_dispersion / branch_explore 封存为失败/消融基线；下一项新方法必须首先具备候选级风险事件语义、模型预测可用性与失败/不评估行动的明确区分，然后通过新的前瞻等成本实验核验。**

本备忘录明确区分“解析层级数学测试”“100/140km 简化飞机筛选模型”和“真实飞机/RCAIDE 高保真认证”；三者不能混称。

### 要特别说明的效应量

- PR58 的 96 个配对属于 **4 个不同自定义数学任务 × 每任务 24 个种子**；结果为 **6/5/85**。这不是 96 个同分布独立真实飞行任务，不应将所有任务并为一项不加限定的确认性总体结论。
- PR60 的每个新策略有 288 次在线真实评价，比较按相同的任务/种子、6 次真实在线评价完成。逐级胜/负/平：branch_mean vs budgeted **11/20/17**；branch_dispersion vs branch_mean **8/12/28**；branch_explore vs branch_dispersion **5/16/27**。每条对比恰好 48 个种子—任务组。
- PR61 的 Beta floor 绑定次数 213/265、231/264、214/264。回退失败比率分别 84.4%、74.9%、92.2%。覆盖点无 GP 风险概率，不能因不在 Brier 分母就忽略其实际评价成本。

## 3. 研究贡献分级

### A 级：已经有直接、可核查的原始证据

1. 将 record completion 与 mission completion、SOC reserve、真实可行约束严格区分。给出完整物理筛选记录总量及事件覆盖。
2. 针对原在线**真实已选候选**做 prequential 概率与结算事件核对，暴露概率过度乐观、模型无预测覆盖以及阶段差异。
3. 新 on-policy 数学实验采用相同初值、真实反馈、不同后验、等评价次数、逐种子 feasible-first 比较，避免混淆终点质量和额外搜索机会。
4. 针对原概率硬门和分支 Beta 风险下限，复算“风险代理上升—风险门无候选—回退—已选点评价失败”的完整数值证据。

### B 级：条件性、探索性证据

- 稀疏 Branin 的部分种子在预算采集下存在质量改善，但跨任务不稳定；相同调用次数下多数配对持平。
- 跨种子回顾性概率校准优于 raw 的部分设置；但该额外训练信息不属于原在线优化器可获得的数据。
- 分支级经验风险、标准差与回退失败存在强观察关联；因分支内连续设计异质、自适应选择和候选选择改变，尚不能将其写为有保证的风险统计量。

### C 级：当前明确不能写成已成立的贡献

- RA-LSBO 系统性优于全 One-hot 或其他传统 BO。
- 风险概率经过可部署、时序有效的校准，或者硬性失败预算有概率安全保证。
- Beta 分支均值加标准差构成有效的置信上界。
- 基于上述数学解析问题的安全表现能外推 100/140km 真实物理任务、RCAIDE 或飞行器。
- 从回顾性日志中证明某个未实际运行的阈值/回退策略效果。

## 4. 小论文定位建议

**路线 I（当前可整理成有证据的研究报告/方法学论文）**：面向层级混合变量潜空间 BO 的 *Risk Semantics, Selected-Point Calibration, and Fallback Failure Modes*。重点不是新优化器获胜，而是严密区分事件、校准与风险门行为，展示对低概率稀疏可行域的数值诊断与负面消融。可写作探索性经验研究、算法失败分析或方法学论文，但投稿前需要评估目标期刊/会议的实验与创新要求；“负面结果本身”不自动成为算法创新。

**路线 II（若必须以新优化算法为小论文主体）**：将本阶段作为问题识别和强基线证据，尚需设计并验证**候选级、前缀时序可用**的风险估计/不确定性与优化收益联合选择机制。不能把被证伪的 branch Beta floor 改个名称当作创新。新贡献必须有清晰的数学条件、可被证伪的核心假设、逐项消融和独立同成本 on-policy 证据。具体门槛见配套协议。

## 5. 建议的下一步决策

**冻结 PR54–61 为对照与根因材料；停止继续“加大风险惩罚或调阈值→重跑同一数据”的研究循环。**

先设计一个候选级风险-收益决策问题，其中每个候选满足概率、该概率的模型误差/数据支持、优化目标收益、以及无法选择候选时的明确行动都可观察、可计费。对 GP 输出置信程度的任何解释必须陈述相关假设；一般的自适应选点、非 IID 分支历史不能自动推出高概率逐设计安全保证。

新研究方法通过门槛检查、候选选择逻辑纯测试、独立种子等工作量真实反馈，再考虑简化飞机筛选的迁移。**PR62 本身不创建 PR63 新算法、不消耗新物理评价。**
