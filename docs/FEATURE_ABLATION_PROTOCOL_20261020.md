# 历史风险特征消融

2026-10-20 制定，作为 P5 的离线诊断，不调用 MDA，不修改正在执行的 120 点验证，不读取其中任何标签。已有历史已在前轮检查过，因此本项是探索性分析，不能改称全新的独立确认。

沿用 v4 随机历史前 180 条训练、后 60 条校准，剩余 60 条及四种策略各 200 条为测试。排除与训练/校准重合的规范化设计及每个测试块内重复设计；跨测试块重合另行报告，不把各块合并成独立重复。

固定四种特征：

- `latent`：现有连续量乘激活掩码、连续掩码及 4 维潜变量。表示仅用前 180 条目标训练，VAE 种子 0、60 epochs。
- `hierarchical_onehot`：相同连续量与掩码，替换潜变量为按设计语法定义、失活部分置零的离散 one-hot，并保留离散激活掩码。
- `plain_onehot`：规范化的连续量和离散 one-hot，不显式提供激活掩码。仍先规范化失活坐标，不人为引入无意义坐标噪声。
- `continuous_mask`：只用连续量乘掩码与连续掩码，移除直接离散编码；掩码本身仍可能携带分支信息。

各特征使用相同 `BinaryRiskHead`：64 棵树、叶节点至少 2 样本、正负类至少各 3 才拟合。RF 种子固定 0–4；这些只是同一历史上的模型随机性重复，不是 5 次独立飞机实验。输入维数改变时默认 RF 特征子采样的维数也变化，因此这是既定实现的特征管线比较，不是单因素因果分离。

逐模型沿用原 sigmoid 校准门槛，不为消融降低样本要求。报告原始和校准后的 Brier、log loss、ECE、0.8 阈值接受数/已知违规数/未知数；每个历史测试块分别比较。不得按测试分数选种子、阈值或树参数。模型与参数、未附标签预测、评分和精确来源身份分别保存。

不据本项自动替换真实执行模型，不据分类评分声称优化收益或联合安全保证。潜空间有效与否须保留负面结果，并在后续独立优化对照中检验。
