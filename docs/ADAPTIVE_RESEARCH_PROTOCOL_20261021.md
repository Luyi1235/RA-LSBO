# RA-LSBO 独立方法修订开发协议

本协议在新受控结果生成前冻结。原始任务方程和旧物理实验不变；
本轮真实MDA新增为0。已查看旧任务和真实标签，本轮属于方法开发，
不是盲测或论文确认实验。不按本轮结果调整模型超参数。

## 受控对照

- 任务：原五类串行失效、原稀疏内部失效两个既有方程。
- 配对种子61、62、63；每任务每种子共同初始600条，前400条训练，
  后200条固定参考校准。另有300条共同静态测试，全部不进入训练或选点。
- 新方法：完整、合并隐藏失效三类、移除风险输入中的VAE潜变量、
  移除余量/对比辅助监督、去校准、去信息探索、去自适应局部搜索，共7种。
- 基线：旧RA、CBO、未经改写的原LSBO提案接口、随机，共4种。
- 共66个试验，每个最多24次廉价受控选点评估，累计上限1584次。
  共同初始600条和静态测试300条的离线标签费用单独计，共5400次廉价方程。
  每个方法最多12次已观测不可行；提前停止和零改进均保留。
- 更新每4次；新方法下此前所有非参考标签立即具备训练资格，无滚动窗口延迟。
  “即时学习”指下一次预定拟合，不代表每个调用后都重新拟合。
- VAE初训200轮、更新20轮、潜维8；GP25步；候选256。
  联合模型3个bootstrap成员，64宽度、12维辅助嵌入、100轮、AdamW 0.003、
  128批次；余量Smooth-L1权重0.2、监督对比权重0.05、温度0.2。
- 风险网络使用带条件掩码的one-hot直接路径，并按消融添加标准化VAE潜变量。
  不是“纯潜空间替代所有离散变量”的效果检验。
- 未分解消融保留“可行、显式不可行、总体隐藏失败”；不删除总体成功信息。
  去辅助监督同时删除余量回归和对比项，本轮不区分这两项的单独贡献。
- 温度拟合至少30个已知最终标签、各类至少5例，范围0.3至3，
  对log温度加0.05平方正则。缺类则恒等映射并标记，不能称校准充分。
  去校准仍拟合同一温度，仅关闭变换，保持训练与其他策略一致。
- 自适应区域初始宽0.4，两次改进乘1.5、四次未改进减半，
  最小0.025后重置0.4；3/4候选局部、1/4全局，有限类别切换。
  去信赖域恢复旧全局/精英扰动候选，不是仅冻结某一个宽度的消融。
- 信息探索在前半程每4次可执行一次，上限3次；以集成熵差作代理。
- 新方法硬调用账本全部按1计费。另记预期不可行成本及半调用量的软额度，
  用剩余调用/额度比例调整风险价格，价格0.25至8。
  软额度不是保证，不作为停机风险界。实际不可行上限单独强制。
- 旧RA保留原门槛、滚动校准和风险扣费；CBO/原LSBO使用全部初始数据。
  它们是整体性能基线，不用于声称新方法某个组件的因果收益。
- 记录前瞻提案、训练ID、参考ID、模型权重与校准标识、真实结算及调用账本。
  复核全部受控真值、训练隔离，以及所有新方法已选点的风险/温度预测回放。
  不将该回放称为全部GP采集值和原LSBO搜索路径的独立审计。

## 真实数据回顾性检验

- 不调用物理评估器，强制allow_mda=False。
- 固定560条历史训练、72条参考，保留原编码器以公平比较风险模块。
- 对既有288条优化观测的共同输入重新预测，排除与训练/参考重合设计，
  报告剩余观测数与唯一设计数；不把历史结果归给新优化器。
- 比较完整、合并机制、one-hot、无辅助监督的原始及温度概率，
  与旧共同历史RF/GP/校准模型作Brier、log-loss诊断。
- 全锚点族5、19分别留出，包括所有邻居；禁止新校准和优化标签进入训练。
  新模型报告“已到达任务求解阶段”条件下的任务失败概率；
  旧RF同样使用原阶段已知标签评分。保留原RF潜变量和one-hot对照。
- 无真实正例的四类失效仍为数据缺口；不靠合成标签填补物理证据。
- 无安全保证、无泛化或显著性预设。负结果不删选，不自动选出最佳消融当完整方法。

受控开发证据与真实回顾性证据分别汇报。只有后续另行冻结的新真实
优化对照，才能检验新方法的飞机优化效率；旧500次真实预算保持累计已用完。
