## 冷启动学习与发现采集

实现两个可单独启用的改动，保留原算法作为对照：

1. `FreshDiscoveryLearning`：当最终可行校准不能启用时，用全部当前历史重新训练原始模型，每次新观测后更新。原校准段加入新的原始模型后，不再被冒充为该模型的校准集。
2. `discovery_rule="constraint_ei"`：发现阶段使用同表示 CBO 的约束采集分数。有可行 incumbent 时结合 Log-EI，无可行点时按原始满足分数排序。它是独立性近似下的排序规则，不是新的校准概率。

两个改动均不放宽原有发现上限 8、RA 风险额度 102、开发阈值 0.8 或总调用上限 112。未校准发现每次仍按风险成本 1 计费，不能进入开发/边界审批。

## 约束感知风险诊断

固定 `min(RF最终可行原始分数, 各必需昂贵约束GP边际分数)`，再在原 60 条校准历史上拟合原有 sigmoid。模型只使用原 180 条训练历史，不用六点结果拟合。这是由旧试点失败启发的探索性公式，旧六点和已查看的历史测试不算新独立验证。

| 数据 | 原校准 Brier | 约束感知 Brier |
| --- | ---: | ---: |
| Random 留出 60 | 0.08529 | 0.03495 |
| LSBO 200 | 0.01441 | 0.01175 |
| Mixed-GA 200 | 0.00136 | 0.00123 |
| One-hot 200 | 0.01051 | 0.00880 |
| RF-BO 200 | 0.04152 | 0.03225 |
| 原六点试验，事后诊断 | 0.48671 | 0.45768 |

总体 Brier 改善不等于高概率接受风险改善：旧六点上，0.8 阈值下仍接受全部六点，仍包含三个违规点。Random、One-hot 和 RF-BO 历史上被接受的违规数分别从 0/0/4 增为 1/1/5，接受总数也变化。不能只报平均评分的好消息。

因此没有启动最初考虑的另一份八点确认试验，而是改为准备专门的边界校准分布验证。该决策基于已经观察到的诊断，不伪装成事前设定的检验结论。现有全局模型不因此获得“可信下界”身份。
