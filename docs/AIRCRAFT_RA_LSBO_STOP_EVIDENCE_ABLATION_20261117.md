# RA-LSBO 冷启动的中止约束证据消融

## 研究问题

PR117 和 PR118 分别检验了独立核训练和定期边界信息评分。两轮均未确认这些改动能在两工况更早找到首个可用设计。本轮直接检验 RA-LSBO 的部分观测机制。在已经知道一次评价提前中止的前提下，将返回的非解析工程约束证据用于冷启动风险 GP，能否更早找到首个可用设计？PR118 固定结果为 8ac4a7f234195990d5011e3b17b49131d62f7961。

| 臂 | 已知未完成评价的非解析约束 GP 监督 | 首解后 |
| --- | --- | --- |
| ra_to_lsbo | 保留所返回的精确值与区间界 | 原版 LSBO，使用全部原始历史 |
| ra_stop_status_to_lsbo | 将这些返回值作为缺失来拟合约束 GP | 相同原版 LSBO |

干预发生在冷启动风险 GP 的监督视图。已完成评价的约束观测、全部完成状态标签、目标观测、解析几何预筛及表示训练均沿用相同实现。原始账本、可用设计的判定以及首解后的后端均使用未遮蔽数据。对照臂中尚未观察到的约束保留其原缺失状态。该试验估计已知中止所返回非解析约束证据的整体增量，精确观测和区间观测作为一组共同干预。

两臂采用 PR118 原有独立训练 RA-LSBO，均保留同一计划覆盖、20% 的计划边界信息评分和回退规则。使用 4 个共享初始设计与 128 个共享冷启动候选。首解出现后，从下一次调用起把全部已评价历史交给原版 LSBO，用满剩余预算。初始已有解时立即交接。每臂 20 次在线评价。任务为 140 km、20 s 步长，4 m/s 逆风与无风增载 24 kg 各使用 40 个新配对种子。

## 主终点和验收

主比较为 ra_to_lsbo 减 ra_stop_status_to_lsbo。只纳入初始无解的种子，以首个可用设计的在线调用序号计分，20 次未找到计 21。分工况报告种子内差的均值及 95% 配对 bootstrap 区间。负值表示使用返回的中止约束证据更快。次要结果为 20 次内发现率、终点可用性优先的胜负平及双方均有解条件下的能耗差。两工况均支持提前才主张跨工况收益。

账本校验依据已结算原始历史重建每次成功拟合的监督视图，并与引擎实际训练前缀摘要核对。计划覆盖及数值拟合失败分别记录。逐种子的 stop_evidence_steps 统计可使用中止约束观测的模型步，在两臂分别记录实际训练保留或遮蔽的步数。初始已有解的两条原版后端轨迹、以及首个共享覆盖决策也须匹配。

| 配置 | 共享初始 + 在线 | 总降阶调用 |
| --- | ---: | ---: |
| stop-evidence-smoke | 8 + 24 | 32 |
| stop-evidence-headwind | 160 + 1600 | 1760 |
| stop-evidence-payload | 160 + 1600 | 1760 |

Smoke 使用历史初始有解和无解种子。正式共 3520 次降阶评价，RCAIDE/MDA 调用为 0。使用 Rcaide_vsp 的 Python 3.9.25 和 run_aircraft_ra_lsbo_comparison.py 执行 plan、run、verify。分析输出需在证据目录外。回传 primary、comparisons、stop_evidence_steps、原始账本、日志与校验和。
