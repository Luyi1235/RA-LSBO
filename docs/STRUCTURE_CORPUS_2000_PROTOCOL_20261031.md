# 2,000条无仿真构型语料：有限表示修订与离线预测检查

2026-10-31。范围：已有模型和历史之上的开发性诊断，不是论文修改、优化器重放或新BO实验。
用户明确补充：论文X-57案例使用2,000条随机生成、可能重复、无需RCAIDE的构型样本，
与初始已评估样本共同训练VAE。本实现继承这一事实；原抽样分布、原始随机种子和全部超参数
未提供，因此不宣称逐字复现X-57实验。当前检查使用12种离散构型的简化飞机，不冒充17连续/7离散X-57案例。

## 不改变的部分

原StructuredRepresentation、PrefixFeatures、风险GP、所有旧优化器、飞机方程、评估预算、
任务距离、原始数据、种子及来源快照一律不改。新模块是opt-in，未接入任何现有pilot默认入口。
不加入自适应专家、风险损失、新采集函数或学习型GP均值；潜变量归一化和核网格也保持旧规则。
没有调用飞机评估器、数学真值、RCAIDE或优化器。仅VAE/GP拟合消耗计算，费用单列。

## 结构数据与监督数据

每个seed用独立NumPy随机流(seed+62000000)，在规范化后的合法构型列表上均匀有放回抽取
恰好2,000条。保留顺序和重复，保存列表索引、频数、独特构型数及哈希。不做真实性能或物理可行性筛选。
这是本实现声明的抽样规律，不推断为原论文随机生成器。不会重抽直到覆盖率满意，也不删少见构型。
每次训练结构语料 = 固定2,000条随机构型 + 当前已评价前缀每个设计的离散构型。
后者包括缺失目标设计；结构合法不等于物理可行。两部分仅进入重构，不制造目标或可行性标签。
性能监督仅用当前历史可信精确目标；未知、基础设施错误及数值错误不提供性能目标。
同一构型多个连续设计的目标按现有构型趋势头处理，本轮不改变性能头输入或损失。

沿用原MMD结构化VAE：4维latent、48宽、batch128、MMD .05、performance 1、entropy .01，
现有初始性能权重渐增；不是改为纯结构预训练。初始训练30epochs，2012行对应16批/轮、480次梯度更新。
2,000不是2,000独特构型，不是2,000次仿真，也不是2,000条GP训练标签。

## 五个固定对照

- old30：旧全语法枚举，从头30epochs；每个检查前缀30次更新。
- old480：同样旧枚举，从头480epochs；匹配corpus_reset的初始总更新次数。
  降低随机语法噪声/改变样本重复分布是语料效应；训练更多本身不是新方法贡献。
- corpus_reset：2,000随机构型+当前已评价结构，联合30epochs，每个前缀从头训练。
- corpus_persistent：首次与corpus_reset完全相同，保留网络和私有随机状态；每新增8条在线历史
  以20epochs、学习率.0004更新，仍回放结构语料。Adam按既有实现每次fit重建，不宣称保留动量。
  离线固定更新位置为0/8/16/24；检查0与29。29处编码器监督前缀为36条，GP前缀41条，明确区分。
  初始480+后续3×320=1,440累计更新。**此后缀总训练量不与old480匹配，不能单独归因于持续学习。**
- onehot：原层级one-hot几何和相同GP，无编码器拟合。

旧30、旧480和reset三组区分训练量/语料；persistent只是训练生命周期候选，不独立宣称最优。
如果需要进一步归因持续训练，必须另行登记累计计算量匹配对照，不能对本轮结果过度解释。
本轮不因重构率不达标而自动增加epoch、改随机种子、追加参数网格或删掉候选。

输入原完整飞机pilot ZIP：

两个任务、全部9911–9918历史；只读旧ev_latent运行。采用提案0和29前缀：12和41条已知记录。

全量80个已有设计，不重复调用真值。目标仅在拟合完成后用于评分，不进入语料、归一化或模型选择。
现有轨迹是原算法产生的适应性样本流，不是新方法的反事实BO轨迹，也不是独立确认集。

缺失保留不补造。预测观测方差=潜函数方差+登记exact_noise对应的尺度化噪声。

时间按训练/预测单列，persistent历史训练费用不隐藏在最终snapshot之外。
本轮检查结构质量及共同历史预测，不证明选点/优化性能提高。

## 结构诊断和检查点

记录编码均值下全部活跃字段正确率、每字段准确率、32次后验抽样下的重构、mu/logvar、
归一化codebook、距离矩阵、训练损失、实际更新次数、语料频数与身份。
使用原始分类头结果，不把规则修复后的合法率冒充原构型重构率。
当前12种已知构型的均值往返12/12为工程目标，未达标如实保留；这是训练语法检查，不是泛化认证。
不以此自动授权BO；还需预测证据。结构随机样本与人工测试不占仿真预算，但训练成本不为零。
检查点仅用NPZ数值数组+JSON，不加载不可信pickle；来源、语料、历史与状态身份均校验。
旧feature身份只对old30且原身份存在的29项检查，跨平台差异不得改历史哈希来强行匹配。
