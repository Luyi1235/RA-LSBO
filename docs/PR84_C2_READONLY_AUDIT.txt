Scope and guardrails
- Pure standard library, python -S. No evaluator, optimizer, candidate generator,
  model fitting, VAE, aircraft or RCAIDE imports/calls.
- Every archive file is checked against its committed Git blob. The outer
  SHA256 manifest and pinned profile manifest must match. Both worktrees must
  have the expected HEAD and be clean. Input bytes are rechecked after audit.
- Rebuild best feasible curves and first feasible calls from observed packets.
  Online failure means either constraint fails, not merely region abort.
  A returned exact objective does NOT imply all constraints are feasible.
- Replay candidate IDs, model/head/prefix receipts, predictions, EI*p selection,
  journal order, the combined event stream, calls and computation bills.
  Prediction values are archived values, not independently refitted GP outputs.
- Recompute C2 factorial effects and the original 12-test Holm family unchanged.
  Missing outcomes stay missing; initial-warm is the original primary stratum.
- Summaries are compared, not blindly trusted. A summary/boolean discrepancy
  is a finding, not an instruction to overwrite the input or rerun C2.
  Unknown source-generation logic remains UNRESOLVED; do not invent a cause.
- Metrics use observable labels of selected evaluated candidates only.
  Stored truth is used only as part of file/record hashes, never for metrics.
  No hidden objective is imputed and no unselected candidate receives truth.
- Brier/log loss/AUROC and fixed ten-bin reliability are descriptive, conditional
  on policy-selected data. Objective error and residual coverage are conditional
  on exact objective feedback. Zero predictive variance is explicitly counted.
  Diagnostics are NOT independent full-domain calibration or causal mediation.
- Preserve arm, task, step, branch and six-step-block stratification. Do not
  average incomparable task objective errors into a scientific claim.
