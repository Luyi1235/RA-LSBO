# 结构化编码器框架与首轮诊断结果

本轮按用户最新要求，先完善结构化潜空间编码器框架，再开展实验。未执行此前拟议的 192 次真实闭环试验；本轮新增真实 MDA 为 0。原 LSBO 及其默认编码器、物理模型、历史结果均未修改。

## 框架完成项

新增 `ra_lsbo/structured_encoder.py` 和 `ra_lsbo/structured_models.py`，实现：

- 论文方向的序数坐标/平滑基、名义嵌入、递归条件掩码和按层级有效解码。
- 仅输入 z 的 MSE 性能头，重构/MMD/性能/解码熵四项损失及分阶段性能权重、初始熵衰减。
- 独立定义论文 GP 输入、RA 风险输入和两种 one-hot/连续掩码基线的列布局。
- 目标先验与残差 GP、多约束独立 GP、多失效风险头、时间隔离校准接口。
- 从头训练和严格追加前缀的低学习率增量更新；更新后旧代理及校准失效。
- 包含权重、数据、源文件、训练轨迹和随机状态的快照；checkpoint 重载及篡改拒绝。
- `StructuredLearningStrategy` 可直接作为既有优化循环的显式可选策略；旧默认路径保持原样。

185 项测试全部通过、无跳过，其中新增 20 项覆盖编码器框架和诊断统计。接口检查包含 4/8 维潜空间、两种 GP 布局，以及现有优化循环中的增量训练。测试日志：`tmp/tests_structured_framework_20261020.log`。

## 第一轮：表示与损失消融

协议 `ENCODER_EXPERIMENT_PROTOCOL_20261020.md`。原历史前 180 条训练、随后 60 条全局校准、最后 60 条历史测试；此前新评估的边界前 60 条局部校准、后 60 条边界测试。所有标签都已被研究者查看，因此属于回顾性诊断。

原编码器、新论文对齐编码器及去性能监督/去熵/去退火/去 MMD 共六种设置，各使用编码器种子 0、1、2、训练 60 轮。RF 固定种子 0，两种 one-hot 基线各训练一个共享模型。共 18 个表示拟合、20 个不同风险模型、2,400 条测试预测。编码器种子不是独立飞机任务。

| 风险输入 | 历史测试：全局校准 Brier | 边界测试：全局校准 Brier | 边界测试：局部校准 Brier |
| --- | ---: | ---: | ---: |
| 原工程潜空间，3 种子均值 | 0.07730 | 0.37154 | 0.23104 |
| 新论文对齐潜空间，3 种子均值 | 0.08259 | 0.36527 | 0.22570 |
| 新编码器去性能监督，3 种子均值 | 0.07949 | 0.36761 | 0.23166 |
| 新编码器去解码熵，3 种子均值 | 0.08216 | 0.36596 | 0.22566 |
| 新编码器固定性能权重，3 种子均值 | 0.07359 | 0.37113 | 0.23652 |
| 新编码器去 MMD，3 种子均值 | 0.07889 | 0.35500 | 0.22130 |
| 层级 one-hot，共享单模型 | 0.06799 | 0.34409 | 0.21334 |
| 普通 one-hot，共享单模型 | 0.06408 | 0.36648 | 0.24162 |

Brier 越低越好。新旧表示在不同数据分布上的相对表现并不一致，未支持潜空间稳定优于 one-hot。熵消融的均值差异很小，不能宣称其收益已被证明；去 MMD 此处均值较低，也不能事后选为确认性结论。

20 个模型在边界局部校准后的 0.8 门槛均零接受。因此本轮也未解决真实优化中的候选供给问题，不把平均 Brier 改善写成风险受控的优化效率提高。

论文对齐性能头只看构型 z，原头还看连续量和掩码；新头在边界目标上的单头 RMSE 较大，不能直接等同于最终残差 GP 效果。二者不是同一输入信息量的预测任务，仍需后续验证完整代理及优化闭环。

独立审计重建了 20 个 RF 及其各自全局/局部校准器，从原始来源重现全部 2,400 条预测和评分；15 个新编码器 checkpoint、185 个来源文件及快照核验通过，原编码器 seed 0 的模型身份及前轮原始预测重现。

结果目录：`runs/encoder_framework_20261020T145347Z_87d07bfa/`，包含 `report.json`、`independent_audit.json`、`encoder_diagnostics.png` 和全部预测、checkpoint。

## 第二轮：结构训练预算与容量

第一轮发现，当前 60 轮下新旧编码器的语法内完整构型恢复率均较低。按 `ENCODER_TRAINING_BUDGET_PROTOCOL_20261020.md` 冻结 4/8 维、60/180/600 轮、三个种子的 18 次训练，只检查训练语法内结构质量，不按风险测试标签选配置。

当前语法共有 280 个有效构型。以下是三个种子均值：

| 潜维数 | 训练轮数 | 完整构型恢复率 | 有效解码头准确率 | 达到预定结构标志的种子 |
| --- | ---: | ---: | ---: | ---: |
| 4 | 60 | 8.69% | 67.35% | 0/3 |
| 4 | 180 | 17.74% | 75.47% | 0/3 |
| 4 | 600 | 32.38% | 83.48% | 0/3 |
| 8 | 60 | 18.21% | 76.50% | 0/3 |
| 8 | 180 | 85.36% | 96.81% | 1/3 |
| 8 | 600 | 100.00% | 100.00% | 3/3 |

预定工程标志为完整恢复至少 0.90、有效头准确率至少 0.97，并非论文规定或泛化/安全保证。8 维、600 轮的三个种子均满足；4 维在本结构和训练设置下仍有恢复瓶颈，不能外推为所有四维 VAE 必然不足。

该结果表明，先前只训练 60 轮的风险比较不能代表充分训练的所有潜空间方法。但结构恢复完善也不自动保证性能相似性、风险区分能力或优化效率更好。训练语法已经被用于重构，不是未见构型测试。

18 个 checkpoint 重载后的结构指标均与原模型一致，来源核验通过，训练/保存/核验耗时合计约 52.7 秒，无新增物理评估。结果目录：`runs/encoder_training_budget_20261020T145846Z_fbafe286/`。

## 第三轮：结构合格候选的风险与增量保持

在前项结构结果之后、执行新风险比较之前固定 `ENCODER_CANDIDATE_PROTOCOL_20261020.md`，只检验 8 维、600 轮配置，未继续按风险测试选维数、轮数、权重或种子。直接重载前项三个 checkpoint，保留相同的 180 条训练及原全局/局部校准和测试划分。

| 风险输入 | 历史测试：全局校准 Brier | 边界测试：全局校准 Brier | 边界测试：局部校准 Brier |
| --- | ---: | ---: | ---: |
| 8 维、600 轮，3 种子均值 | 0.06130 | 0.36419 | 0.23791 |
| 层级 one-hot，共享单模型 | 0.06799 | 0.34409 | 0.21334 |
| 普通 one-hot，共享单模型 | 0.06408 | 0.36648 | 0.24162 |

充分训练后，历史测试均值有所改善，但三个种子的历史 Brier 范围为 0.05302--0.07158；不是每个种子都领先。边界局部三个种子为 0.24478、0.23248、0.23647，均高于层级 one-hot。五个模型在局部 0.8 门槛仍全部零接受。完整结构恢复并未自动解决边界风险区分与候选供给；目前仍无跨分布稳定优于 one-hot 的证据。

三种编码器种子共享测试标签，两种 one-hot 参考也与前轮共享，不是新独立任务。全部标签此前已被查看，不能把本项升级为前瞻确认或优化收益。

静态风险预测保存后，另行检查结构增量保持：三个种子分别从 180 条历史训练前缀，按 200、220、240 条严格追加，均执行 20 轮低学习率更新。9 次更新后，280 个训练语法构型的完整恢复率和有效头准确率全部保持 100%；同一最终 240 条前缀从头训练的三个对照也均为 100%。这支持当前三次历史更新的结构保持，不代表长期在线稳定性、风险预测保持或边界分布适应。

相邻增量版本的未对齐潜坐标 RMS 位移为 0.48535--1.30756。因此即使构型恢复不变，旧风险头、GP 和校准器也不能直接沿用；框架已强制随表示版本更新重建这些对象。本项未将曾用于全局校准的历史追加数据再次当作增量模型的独立校准数据。

独立审计重建 5 个风险模型、600 条测试预测和全部评分，并重算 12 个增量/重训 checkpoint 的结构指标；3 个静态 checkpoint、200 个来源及内容快照核验通过。两种 one-hot 的全部 240 条预测逐项重现首轮参考。结果目录：`runs/encoder_candidate_20261020T150955Z_ee3d7ef4/`，图为 `candidate_validation.png`。

## 当前可使用的配置与边界

`configs/structured_encoder_structural_candidate.json` 保存 8 维、600 轮候选。它获得语法内结构恢复及三次历史增量更新保持的诊断支持，也已完成初步回顾性风险对照，但未显示跨分布稳定领先；不自动替换原模型。长期增量训练、完整目标/约束代理的预测比较和完整优化对照仍未完成。

使用接口：

```python
import json
from ra_lsbo.structured_encoder import EncoderSettings
from ra_lsbo.structured_models import fit_structured_models

config = EncoderSettings(**json.load(open(
    "configs/structured_encoder_structural_candidate.json", encoding="utf-8")))
features, risks, responses, calibrated = fit_structured_models(
    base_project, variables, training, calibration,
    encoder_settings=config, encoder_seed=0, risk_view="latent")
```

配置、论文方法衔接和所有接口说明见 `STRUCTURED_ENCODER_FRAMEWORK_20261020.md`。当前是 19 变量工程分支；框架中的性能头、损失和退火方向已补齐，但不宣称严格复现论文全部超参数、24 变量物理任务或优化结果。
