# RA-LSBO：混合观测后验与局部连续优化的组合结果

日期：2026-10-26。对应独立试验目录现归档于 `archive/historical_research/2026-10-26/results/partial_refinement_20261026`。
这是开发阶段的配对比较，不是最终论文验证或飞行安全认证。

## 1. 已实现的框架

本轮保留原 LSBO 的结构化表示、分支精英邻域、活跃连续变量局部优化和自适应半径，
将局部搜索的驱动量换为能够处理精确数值、符号/区间反馈及缺失输出的混合观测 GP 后验。
实现位于 `ra_lsbo/partial_refinement/`，原 LSBO 和前一轮冻结实现均未改写。

- 输入采用掩码后的连续坐标、条件掩码及结构化离散潜变量；提供相同接口的层级 one-hot 对照。
- 目标、各非解析约束和完成状态分别建模；未知/基础设施异常不伪装成物理失败。
  区间观测通过 EP 近似处理，不补造约束数值或目标值。
- 新增连续/掩码/离散分组度量的 Matérn-5/2 核。每个输出只用当前训练前缀的近似证据，
  从八组连续、离散长度组合中选取一组；保留旧标量核作为对照。
  这是分组长度选择，不是完整 ARD 或超参数后验积分。
- 每轮先生成192个全局候选，再选最多4个分支，每分支增加12个局部随机点并进行最多2次
  SLSQP连续搜索，每次最多25轮。有可行精英的分支使用邻域，没有精英则在完整连续域探索。
- 只移动活跃连续变量，保持层级构型合法；局部结果与全局候选合并后，使用同一采集规则重评分。
  模型拟合和连续搜索不调用真实评价器。保留可行发现、平衡改进、边界信息与空支持恢复模式。
- 每次选点绑定训练前缀、模型、候选池、后验、局部边界及反馈身份，保存完整可重放记录。

方法依据及明确的复现边界见 [主协议](PARTIAL_REFINEMENT_PROTOCOL_20261026.md)。
局部半径策略沿用 LSBO 工程规则，不把本文实现称为 SCBO 的完整复现；
独立输出概率乘积也不等于有相关性保证的联合安全概率。

## 2. 算例和预算

任务A继续使用声明为自定义扩展的层级 Branin；三个12点初始集来自上一轮开发数据，
不是全新留出验证。任务B固定为140km巡航的简化电动飞机，仍采用原低阶气动、推进和电池模型。
两个任务均只有4种有效离散构型，尚不足以代表大规模层级混合空间。

飞机先用独立、经过相同解析几何筛选的30点资格面板检验，结果为 **2/30可行**，
Wilson 95%区间为 **1.85%至21.32%**，未知物理结果为0。两个人工优化之外发现的历史可行锚点
在10s、5s步长下仍可行，与20s的状态及所有约束符号一致；SOC误差小于7.7e-7，
电流余量误差小于1.3e-9，电压余量误差小于5.2e-7。
因此通过预定的点估计开发门槛，但不能声称精确证明总体可行率低于某一数值。
资格面板和锚点不进入优化训练。

主比较为2任务、3配对种子、5方法，每组12初始点及最多12在线评价。
三种局部搜索对照保持相同搜索上限；全局消融刻意去掉局部开销，原 LSBO 保持其原生搜索方式。
因此这是实际算法价值与开销的比较，不是所有方法等 CPU 的理论比较。

主计划上限430次，实际416次。原 LSBO 两组因原生连续失败规则在5次在线评价后停止。
为排除提前停止造成的优势，另行前瞻登记了
[完整预算次要控制](LSBO_BUDGET_CONTROL_PROTOCOL_20261026.md)：只将该阈值从5改为12，
其他原生行为保留，先验证并复用58个已有前缀评价，再补足14个未执行评价。
次要控制在观察到提前停止后登记，不能包装成主试验最初预注册的对比。

**本轮完整计划上限472次，实际新增430次廉价模型调用，新增RCAIDE MDA为0。**
其中主比较346次在线、飞机初始36次、资格与步长检查34次，次要控制新增14次。
这与此前已结束的491次研究分开计数；重复设计在不同方法的新在线调用仍实际计费。

## 3. 配对结果

以下均为包含初始点的最优已观测可行目标，越小越好。三个种子依次为8201、8202、8203。
“在线可行”只统计新增在线评价，不把初始可行点计入。

| 方法 | Branin三个种子的终点 | Branin在线可行 | 飞机三个种子的终点/kWh | 飞机在线可行 |
| --- | --- | --- | --- | --- |
| 潜空间＋分组核＋局部搜索 | 0.8774 / 16.5923 / 1.8026 | 15/36 | 36.86245 / 40.40739 / 36.89568 | 16/36 |
| one-hot＋分组核＋局部搜索 | 5.2662 / 1.1396 / 12.5745 | 15/36 | 36.86246 / 37.08436 / 36.89505 | 18/36 |
| 潜空间＋分组核，仅全局候选 | 2.5241 / 20.2630 / 34.0463 | 14/36 | 37.36833 / 37.78856 / 37.36795 | 15/36 |
| 潜空间＋旧核＋局部搜索 | 36.2085 / 20.2630 / 35.7754 | 1/36 | 36.85537 / 37.01689 / 36.89534 | 17/36 |
| 原LSBO，原生停止规则 | 8.5719 / 19.0699 / 无可行 | 13/29 | 无可行 / 37.39081 / 37.46004 | 14/29 |
| 原LSBO，完整预算次要控制 | 8.5719 / 19.0699 / 29.7953 | 18/36 | 40.17521 / 37.39081 / 37.46004 | 15/36 |

完整新组合在 Branin 相对完整预算原 LSBO 为3胜0负，相对不做局部搜索为3胜0负；
飞机分别为2胜1负、2胜1负。这是三个种子的开发性结果，没有充分统计证据支持总体稳定优势。
完整新组合在飞机8202种子明显退化至40.407kWh，比 one-hot 差约3.323kWh，
也差于全局候选版及完整预算原 LSBO，不能删去此结果。

潜空间相对 one-hot：Branin为2胜1负；飞机原始数值排序为1胜2负，但8201差0.008Wh、
8203差0.630Wh，均不应包装为有工程意义的胜负。飞机的明显差异集中在8202的退化。
新核相对旧核在 Branin改善明显，在飞机三个种子均数值落后，其中两个差异不足8Wh。
因此本轮没有证明潜空间或新分组核的独立稳定收益，不替换原默认方法。

对飞机8202已保存轨迹的事后只读检查发现，完整方法的12次评价中，7次选择分布式双桨分支，
共8次因SOC储备不足而提前终止；one-hot只选择双桨2次，SOC提前终止为0。
全局候选版与旧核局部版的SOC提前终止均为2次。
这将退化具体定位为“较多预算花在SOC不可行区域，且未达到较好的可行终点”，
并非隐藏数值求解失败。它尚不能区分核长度、表示、局部搜索和后续数据分布各自的因果作用。
后续应检查失败分支边界的泛化与短预算探索分配，不能只凭这条开发轨迹修改惩罚后宣布解决。

## 4. 局部贡献、风险预测及开销

完整方法在 Branin 的36/36次、飞机的34/36次最终选择来自局部增广部分。
这包括局部随机点、SLSQP端点和有效访问点，不能全部算作连续求解器的独立贡献。
局部与全局消融支持保留该组合，但没有单独分离“局部随机点”和“SLSQP”的因果贡献。

两个任务各进行了288次局部求解，成功标志分别为220、231次；
记录的局部后验查询分别为22,390和17,446次，不计为真值模型调用。
完整方法三种子合计用时约119s和182s，全局消融约84s和117s；
原 LSBO 主比较约14s和39s，但其部分轨迹提前停止，不能直接作为完整预算耗时比较。
这只是本机本次运行的诊断；连续搜索与新后验有明确计算开销。

共同面板来自每个任务相同的30个设计，三个种子的初始前缀分别预测；
不能把它写成每任务90个独立测试设计。

| 初始前缀模型 | Branin平均Brier | 飞机平均Brier |
| --- | --- | --- |
| 分组核＋潜空间 | 0.045338 | 0.072922 |
| 分组核＋one-hot | 0.047882 | 0.074717 |
| 旧核＋潜空间 | 0.044976 | 0.069781 |
| 初始可行率平滑常数预测 | 0.036719 | 0.068540 |

以上为最终可行性乘积代理的概率评分，越低越好。完整方法没有胜过常数预测，
不能宣称风险概率已校准或预测有效。稀疏正例会使普通Brier偏向负类；
补充的事后类别平衡Brier中，飞机分组潜空间约0.420，旧核约0.329，同样未显示新核优势。
类别分数和常数基线是事后诊断，没有用于选核、调参或主比较升级判定。

所有在线任务的隐藏失败正例为0，主要风险来自显式物理约束及早停后的部分输出。
因此本轮检验了混合反馈与优化闭环，不能据此宣称五类隐藏失效模型已获验证。
本轮也没有在相同新核与局部搜索下删除区间标签的匹配消融；
前一轮旧框架中的相关消融不能替代这一对照。因此相对原 LSBO 的收益尚不能独立归因于混合观测。

## 5. 验证及研究判定

71项针对性测试通过，覆盖分组度量的独立数值核对、EP语义、采集值、局部连续搜索、
非活跃变量、无真值搜索、训练前缀、反馈保护、积分门槛和预算控制。
主试验119项源码/数据绑定、346个选点及18个共同面板模型预测全部恢复一致，
416条主试验已启动调用均有结算，审计通过。
完整预算控制另通过72个轨迹选点重放；所有重放新增真值均为0。
本轮及前两阶段的119、110、106项冻结源绑定最终逐项检查均未改变。
旧MDA只读审计工具另有8项自测通过，并用Python3.14独立复算确认原4013个文件未变化。

可继续保留的研发底座是“结构化表示＋混合反馈后验＋分支局部优化”，
其各项接口、全局/局部统一重评分和预算审计已经落地。
仍需解决的是小样本下的风险概率质量、表示/核选择的鲁棒性，以及更复杂层级构型上的潜空间收益。
当前八组候选核按单个近似证据值选最优，未传播超参数不确定性；
这是一项明确的方法限制，但本次结果不能单独证明它是8202退化的原因。

下一步优先开展无新MDA的逐轮后验与选点诊断，针对上述退化形成可检验的模型修订，
再登记独立种子及更丰富的公开层级基准。不能在这三个开发种子上不断调参后宣称独立验证。
140km模型仍是简化电动飞机，不是RCAIDE X57验证；最终单一飞机MDA须另行完成资格门槛。

旧RCAIDE资格实验的中断也已独立只读核查，见
[中断证据与未知结果](COMPACT_MDA_INTERRUPTION_20261026.md)。
其第37次调用仍计费，缺少可恢复终态，物理标签保持未知；未重试、未结算、未宣布资格通过。
