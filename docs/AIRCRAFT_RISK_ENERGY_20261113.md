# 显式风险和目标潜空间的飞机能耗优化试点

PR97 固定结果 4ce4b4f91746b92bf8831ba984e5186c182ebb45。在 n=48，覆盖→Brier 相对覆盖→边界的联合 Brier 均值差 −0.000680、配对中位数差 +0.002170、5 胜 7 负。可行召回均值低 6.37 个百分点。单独的 Brier 采集相对边界差 −0.000180、5 胜 7 负。两项均不支持稳定的预测优势，故本轮研究固定风险代理加入实际能耗选点后有没有增量，并单独检验目标潜空间。

## 方法

沿用同一 140 km 简化电动飞机、20 s 积分步长和几何预筛选。四个实验臂是目标显式或 LSBO 构型潜空间，分别配 EI 或可行概率乘 EI（CEI）。两种目标视图使用同一 StableGroupedHead 目标 GP 和 4×2 核网格。目标训练使用可信完整评价返回的精确能耗，包括已知工程不可行但有精确能耗的点。目标 GP 不使用提前停止后的能耗前缀。已知可行且完成评价的精确能耗才可作为 incumbent。潜空间采用现有结构语料、初始共同观测和每隔 8 次在线评价的本臂观测更新，同一计划及候选池。其他搜索组件（原生 LSBO 局部搜索、VAE 均值先验、连续候选优化）不属于此匹配消融。

所有臂用显式层级特征拟合同一个类型的六约束风险模型。CEI 使用原始边际可行概率乘积，EI 的风险预测用于评分诊断。风险模型仍使用真实精确、区间和缺失证据。没有可用 incumbent 或精确能耗不足两个时，四臂共同采用显式 maximin 覆盖，之后才转入能耗选点。这使主比较针对已有可用数据后加风险权重的作用。首次可行时间用于说明启动条件，并非本轮方法可预期改善的端点。候选评分和实际选点在评价前写入；留出仿真在每种子的全部在线评价完成后执行。

## 复核与终点

主比较是在 n=48 的 CEI 潜空间对 EI 潜空间。按种子先比能否找到可用可行解，双方均有解再比最低观测精确能耗。双无解记平，单方无解时不填能耗。次比较为显式 CEI 对显式 EI 和两个固定采集规则下的潜空间对显式目标表示。报告配对胜负、共同有解能耗差和实际在线可行、不可行、未知调用差。留出 Brier 与召回是诊断。核验器复算候选评分组合、前缀资格和更新调度，依据原始记录生成逐种子配对，并区分覆盖回退和实际 EI/CEI 选点次数。它不重拟合代理，也不执行新评价。

工作机使用现有 Rcaide_vsp 环境和固定代码提交。先运行专项单元测试及 plan，再依次 run/verify/analyze energy-smoke、run/verify/analyze energy-pilot。输出放在代码目录之外，技术失败时保留日志和已结算账本。成功后从固定代码提交建立独立结果分支，归档原始两阶段证据、外层分析和日志。原始证据使用 Git -text。
