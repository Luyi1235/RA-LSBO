# PR59：旧风险代理失效机理核验（PR58 独立同成本实验的只读诊断）

## 背景和决策

PR58 新 24 种子 × 4 任务的真实等六次解析评价，预算策略与语义修正对照在 96 个配对种子中为 6 优、5 劣、85 平；没有稳定同成本优化优势。预算算法 576 次在线选点里 47 次无法满足原代理预测失败额度，42 次回退点实际不可行。稀疏 Branin/Rosenbrock 中，预测失败率继续系统性偏乐观。旧的“边际 GP 约束概率乘积 + 剩余失败额度”应视为**探索性失败基线**，而不是已经支持飞行安全或性能优势的创新成果。

在设计新机制之前，本 PR 直接量化：风险过度乐观发生于哪个任务、选点阶段、在线步数、预测概率区间，以及在没有模型预测或无法满足预算额度时真实失败如何分布。

## 固定输入及身份

唯一原始输入是 PR58 已经完成的完整固定报告：结果 commit 84c8a786c907cad5e2b333964c318fac9fdea25d，文件 fixed_six_onpolicy_report.json，Git blob SHA1 d5029c505b738ec3da471e5bc2b38e8dd0fefadd，原实验代码 SHA 7d8e5edb0cd9db6bc6525a8f9989591388c71af5。

本 PR 在加载和结束后核验原始 Git blob SHA，逐条校验 288 个 trial、1,728 次在线真实选点评价、每次观测事件、风险概率范围、原来预算政策历史前缀的已观察失败数与原收据一致、三方法共享初始信息的 SHA。**仅报告已经实际选中的候选**，不推断未评价候选的风险和反事实收益。

## 冻结诊断

每任务 × 每算法，另按 boundary / feasible discovery / feasible improvement / coverage，及在线步数 0..5 分组。诊断输出：

- 每组真实选点总量、有有效 GP 风险概率的次数、无概率的覆盖回退次数、已观察不可行率。
- 预测平均失败率、实际已选点评价失败率、概率偏差（预测减实际；负值为乐观）、Brier、log loss、5 bin ECE 和不同风险概率区间的可靠性表。
- 预测失败概率不超过 0.2 的“看似安全”选点中仍然失败的次数及其实际失败率；这只是诊断阈值，不是任何可靠的安全过滤器。
- 预算代理失败时的无候选可满足门槛回退数、其中真实失败数；保留模型无预测候选费用，不填造风险概率。
- 固定 20261105 种子、1,000 次种子层级 bootstrap，对模型已选点的平均预测偏差给出**描述性** 95% 百分位区间。整个 trial 的种子簇共同重采样，绝不把相邻在线评价当成独立样本；不作安全或因果置信声明。

此分组是在观察 PR58 后提出的探索性诊断；没有对不同方法的风险模型输出进行同点反事实比较（各方法真实选点不同），没有进行任何 calibration fit，也没有为旧策略暗中加新校准。

## 后续研究选择

如果分组诊断确认主要问题来自校准置信不足、无预测覆盖与极端误判，应考虑单独研究保守风险界、贝叶斯后验不确定性传播、在线小样本/分阶段分布漂移和收益—风险联合采集，而不是微调旧概率阈值反复宣称优势。算法改造前须先冻结目标事件、分离训练/评估，且采用真实自选轨迹和同等评价预算进行新对照。PR59 本身不是新风险优化器，也不能证明新方法有效。
