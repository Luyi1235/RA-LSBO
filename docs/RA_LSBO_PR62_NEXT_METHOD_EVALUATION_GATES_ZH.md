# PR62 | 下一项风险算法的研究协议与进入实验的门槛

**性质：研究设计约束，不是新算法源代码、正式预注册、统计保证或已经完成的实验。** 此协议根据 PR50–61 已知结果编制；未来新方法若遵循本协议，仍应明确其“看过既往证据后设计”的事实。不得将此协议倒签成 PR54–61 的先验研究计划。

## 1. 要解决的可检验问题

给定已有前缀 D_t、合法的层级连续—离散候选集 C_t、剩余解析评价工作量 N_t，和对每个已评价设计的**物理语义明确**的可行真值 y，算法需要决定：
- 对候选 x 估计的是哪一个事件：全部所需非解析物理约束同时满足、SOC/任务完成，还是程序记录结束。绝不能用 status completion 代替任务完成。
- 模型是否真正给出该候选的风险概率，以及候选在其训练支持下有多可靠；如果 GP 数值失败、未训练或走 coverage，这次决策必须显式记为“无风险概率”。
- 候选的目标收益、预测失败风险、风险不确定性和选点评价成本如何共同决定下一步动作。
- 当所有候选都不满足所定义的准入条件时，明确区分**继续评价有风险候选、为信息价值探索、降低评价精度、拒绝本次评价/停止**。不同动作有不同成本，不能将不评价伪装成零风险成功，也不能将高风险探索标成通过预算门。

最终评估目标不是“所有失败次数越少越好”，而是**在事先声明的评价/失败资源约束和同等工作量下，获得已证实的高质量可行设计**，同时准确报告模型预测是否可信。

## 2. 候选级风险与不确定性的最低科学要求

### G0：事件和输出定义

- 约束联合可行目标：所有实际必须满足的非解析约束在真实结算中可用且满足；未知、异常终止、部分反馈与真实不可行不能不加区别地当成负标签。
- 对简化飞机筛选，另保存 SOC 任务完成事件。PR50 的 SOC 与任务完成恰好吻合只适用于那批原始档案，不能把这种相等性当作一般物理定律。
- 同一个 SOC 事件不能被 status 和 SOC GP 当作两个独立失败因子重复相乘。风险/可靠性数值必须说明是否是边际概率乘积代理，不能仅因值在 [0,1] 就标记为“保守联合可行概率”。

### G1：候选级建模，不再把分支失败率直接当设计风险

离散分支内仍有多维连续变量，适航/任务可行边界会随连续变量变化。PR60 的 Beta(1,1) 分支下限混合了同分支不同连续位置、选点策略又自适应改变了样本分布，不满足未经解释的二项 IID 假设。

候选级模型至少要满足：当前 x 的特征与其 GP 预测逐个绑定；风险估计必须是 **仅基于 t 之前的数据 D_t**；记录候选在连续—离散空间中的有效训练支持、输出缺失情况与模型不确定性。若引入统计置信界，必须明确其适用的采样、模型/核和时序假设；没有这些假设只能说是**风险不确定性启发式**，不能标安全。

下一种新风险模型须先做解析监督任务的**预结果预测测试**（原轨迹或新按规定生成的已评价候选）。报告 risk-Brier、LogLoss、可靠性分箱、极低预测风险点的实际失败率、覆盖缺失率和种子聚类差异。按优化阶段/任务/样本量分层展示；绝不在同一测试种子的结果上同时拟合校准与打分。

### G2：风险门的“全候选不可用”策略必须是一等公民

PR61 已证实：附加风险 floor 使 80–88% 的已评分分支选点修正风险；无候选满足门槛的回退频次从 22/266 上升到 109/265、175/264、231/264，且回退的实际失败极高。

因此下一个算法的核心不应是“更大风险惩罚/更高 Beta 分位数”，而应独立规定当模型没有可信可行候选时的动作集与风险记账。必须报告以下全部数量，不能只显示被接受候选：
1. 模型真正预测且有可用支持的候选/步骤；
2. 原约束乐观支持缺失或 GP/表示失败的 coverage 决策；
3. 有候选但没有通过风险判据的决策；
4. 主动评价一个被认为高风险的设计、其信息价值代理、真实结果及成本；
5. 选择 abstain/stop 的步骤以及牺牲的搜索机会与成本。

**如果设计允许 abstain/stop，那么不再属于“每臂恰好 6 次真实调用”的旧对照。** 需同时比较相同最大可用预算下的真实评价数、停止时最优可行目标、拒评率和成本归一化效用，不能通过填充“假想无风险调用”伪造等工作量。

### G3：收益—风险联合决策而非先过滤到空再随机回退

如果考虑软约束或约束 EI 一类采集，必须提前声明数学形式、单位和哪些量仅是启发式，以及不同权重的物理意义。至少保持一个没有新 UQ 的原生完整优化收益对照；当新策略变得“更加保守却退化为无候选”时，应记录其失效而非自动默许回退。

设计消融时逐次只改变一个可解释元素：
- 可行风险概率的建模方式；
- 不确定性如何改变候选评价价值；
- 无可信候选时采取什么行动；
- 是否采用阶段相关策略或只依赖历史的校准。

PR60 已经显示“Beta 均值”“Beta 均值+标准差”“最大分支不确定性回退”三个变化是**不成功的尝试**；下一方案须有不同的候选级信息或决策理论依据，而不只是改权重。

## 3. 同成本新闭环试验的进入条件

| 阶段 | 需要交付的实际证据 | 不通过时的动作 |
|---|---|---|
| E0：语义/合法性单测 | 仅使用真实前缀标签；每个候选 GP 预测与最终选点绑定；无预测覆盖不会被填假概率；任务完成/SOC/status 明确区分 | 修复算法和审计，禁止开始试验 |
| E1：解析预测压力测试 | 在**与新方法控制环不重叠**的验证种子/任务上报告校准与极低风险真实失败、coverage、模型数值失效；小样本不以事后全种子校准冒充在线信息 | 不将无效风险分数接入硬门，继续模型研究 |
| E2：候选/空门规则纯测试 | 构造没有候选通过、全候选高风险、GP 失败、极端小样本、同分支异质连续设计等场景；核对行动和实际失败成本 | 调整动作语义/规则，重新冻结版本 |
| E3：前瞻等资源 on-policy | 新种子、相同 12 个初值与候选抽样流、各方法真实重新拟合、预先固定评价预算；分析 feasible-first 全种子配对胜/负/平、双方均可行时的最优目标、真实不可行、工作量、拒评、无预测回退 | 如果优化质量和风险权衡没有改善，诚实记录负结论，禁止声称领先 |
| E4：跨函数独立重复 | 至少两个层级解析函数族、普通/稀疏约束、不同冷启动状态；记录病例级而非仅总体均值；**所有参数在独立重复开始前固定** | 不把任务特定改善外推到全部层级问题 |
| E5：物理任务迁移 | 独立检查 100/140km 简化飞机源、约束、数值稳定性及稀疏可行域资格；随后独立种子新 on-policy 物理评价 | 未过门不得声称飞推控安全或真实飞行收益 |

推荐在 E3 使用 PR58 类型的等六次调用作为一种可复核对照；如存在更长预算/可拒评动作，则另外设置相同**最大资源预算**及成本/停止函数，不能将两种结论混写。种子、样本量和失败判据必须在看到新结果前冻结；不应通过选出获胜种子反复重跑提高胜率。

论文不能只比较平均目标：要提供极端失败率和最坏风险、冷启动可行发现、无预测比例、策略操作的可解释性，以及对照的真实消耗。所选择的“主要目标/次要指标”在后续 PR 代码和计划里写成固定字段。

## 4. 下一轮算法代码设计暂不启动的理由

PR50–61 已有多个阶段的完整数据，最主要的负结果不仅是预测偏差，还包括硬风险门与不确定性代理组合后的*选择机制退化*。在尚未明确新候选级风险定义、训练假设、空门动作、评价成本与主终点之前，直接构建 PR63 新采集策略很可能重复 PR60 的失败路线。

**下一阶段先完成该数学协议的内部评审和可实现性定义，再在独立 PR 上创建算法原型与严格 E0/E2 单元测试。** 如果只有临时经验系数，没有独立假设和失败停止规则，就不投入 100/140km 飞机评价预算。

PR62 为阶段性研究设计，不是对后续新方法有效性作承诺，也不进行任何异步运行。
