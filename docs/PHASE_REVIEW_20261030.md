## 3. 科学决策：停止调覆盖，冻结控制进入表示机制检验

保留原先声明的phase_discovery为参考控制，不因Branin结果改选phase_coverage。两者均保留为历史候选，不宣称已找到最终最佳算法。接下来先回答：潜空间是否提供超过层级onehot、随机发现后相同局部开发的独立增量？

新增可选机制是逐约束、因果时序的表示信任：冷阶段并行预测latent与hierarchical-onehot约束头；真实结果返回后用exact密度或合法interval概率更新每项约束的专家权重；missing/unknown不更新。目标和完成头保持latent，首个原始可用可行解后关闭双专家，恢复原latent开发。初值只训练、不进行回顾性权重打分。

它可能减少不恰当的跨构型共享，但当前数据没有证明该负迁移是主因，也没有证明新机制有效。所有负例时两专家都可能失准；权重可能早期集中；新增计算成本必须披露。

GP组合、预测似然加权、删失GP不是新发明。CBOB已处理混合观测与平衡探索；Lu等已研究BO中的GP组合；prequential研究早已采用顺序预测评分。合理的贡献候选是：层级部分反馈下的逐输出表示信任及其与发现/开发分工的可验证耦合。需超越等权、单表示及简单混合控制，不能只用新名称宣称原创。详见EVIDENCE_TRANSFER_PROTOCOL_20261030.md及其中原始文献。

## 4. 已实现的下一筛查与验收规则

六组random、ev_latent、ev_onehot、ev_random_then_latent、ev_equal、ev_prequential。equal与prequential计算努力匹配；两个单表示组的计算量较少，时间单列。只变更声明的表示/权重策略，不改任务、物理约束、EP或核网格。

新分配开发种子9801–9808、两个现有稀疏任务、12共同初值、每方法30在线：3108上限。先112smoke后pilot，共3220研究上限；人工/廉价测试求值、历史费用另计。旧20种子已反复观察，不再继续用它们定向调参。8种子只是机制筛查，冷分层可能很小，不能形成独立确认结论，也不能因暖初值过多换种子。

主要看全部运行及冷分层可行发现、删失成本，其次条件目标分母、暖配对、权重/预测评分及耗时。adaptive若不超过equal或简单random-then-latent，优先保留简单方法。该筛查不能证明一般有限区间价值，因为当前数学反馈主要是符号。

之后应优先设计具有真实分支权衡与合法有限区间的机制任务、接入可核验CBOB参考，再冻结算法和独立确认设计。原representation/baselines完整入口仍暂停，不自动执行；飞机MDA需要单独资格与预算。这些未来项没有冒充完成。

## 5. 一个有用但不能冒称原创的理论边界

对固定约束，沿同一条已实现的冷阶段观测序列，设两个专家在每次评价前给出的似然为L_t,m，初始权重均为1/2。精确算术下，标准指数加权满足：

S_mix = -log[(exp(-S_latent)+exp(-S_onehot))/2] <= min(S_latent,S_onehot)+log(2)。

这是把逐步混合似然乘积展开、消去权重归一化因子得到的经典恒等式/界，不是新的BO收敛定理。专家可依赖过去数据，但双方必须对相同候选和相同实际观测事件评分；缺失步骤跳过。它仅与“同一路径上哪一个专家预测更好”比较，不与两个专家独立运行产生的不同优化轨迹比较。不同约束的量纲/观测空间也不能任意混加。

因此它可作为评分实现和研究解释的基准，却不保证可行发现率、最优值、联合概率校准、浮点程序严格等式或物理安全。论文若采用该说明，应明确属于已有聚合原理及其在本观测协议中的应用，而不是新理论贡献。
