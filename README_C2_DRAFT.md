# Phase C2 — risk-head × objective-head update attribution

C1/C1R provides directionally positive risk-EI online-update evidence on known
tasks, with increased infeasible calls and fewer exact objective labels.
C2 will separate risk-head and objective-head update effects using a 2×2
factorial while preserving the same acquisition, evaluator, and call budget.

**This is a development draft, not an executable experiment. Do not run it.**
See [Issue #82](https://github.com/Luyi1235/RA-LSBO/issues/82) and
[protocol](docs/PHASE_C2_HEAD_FACTORIAL.txt).
