## 当前问题

在同一48条初始数据、相同真实调用预算下，风险引导是否帮助获取有用的可观测目标数据，在线更新这些数据是否改善最终可行设计？

四个主臂组成2×2：普通EI/风险加权EI × 初始代理冻结/自身反馈更新。纯风险更新和与标签无关的哈希排序为参照。保持原生EP-GP、显式特征、4×2核网格和部分观测契约，不加入前瞻、信息奖励、风险阈值或VAE。

冻结后验不等于冻结incumbent：所有EI臂仍使用自身当前最佳可行目标。没有可行初值的组不剔除，采用明确的共同回退并单独报告；主比较预先固定为initial_warm的24次在线评价终点。新增标签数是结果，不能持续抽样凑标签却漏计失败。

只评价实际选中的点，不再购买完整候选池真值。GP更新发生且单独计账；VAE、幻想、飞机/RCAIDE为0。共同调用预算不等于共同计算时间。本轮不比较初始/在线预算的最优分配，不运行预留s4–s7，不外推安全或新算法优势。
