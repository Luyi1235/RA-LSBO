## 本轮只改变一件事

同一批真实可观测训练数据、同一目标 GP、同一风险 GP、同一候选池和可行 incumbent 下，比较 **EI** 与 **EI×联合可行概率**。均匀哈希排序、纯风险排序为参照。每个训练样本量只拟合一次，再向四个策略提供相同预测；不为新方法增加标签或重训一个更好的目标模型。

所有候选排名在池内真实评价之前封存。只做固定排名前缀（预算 1/2/4/6/12），不随所选点反馈重训，不声称是联合批量 EI 或序贯优化。冷启动组保留，但两个 EI 策略在没有可行 incumbent 时采用相同均匀排序，单独报告。主检验预先限定为四个构型权衡开发任务、n=48、k=6 的 warm 组，旧 sparse 和其他 n/k 为次要分析。
